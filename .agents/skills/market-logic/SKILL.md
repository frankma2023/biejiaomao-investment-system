# 市场交易逻辑（market-logic）

## 0. 定位与铁律

把「今天为什么涨」从**事后编故事**变成**可核对的传导链**。

铁律，违反即不合格：

1. **先出事实，再谈逻辑。** 盘面数字未列全之前，不许写任何归因。
2. **每条传导链必须给「预期符号」，并当场与盘面对照。** 符号错了就记入反例库，不许圆回来。
3. **区分事实 / 推断 / 待验证。** 三者不得混写。
4. **时区纪律：A 股 T 日交易的是美东 T-1 夜间。** 隔夜事件对 A 股的影响要到 T+1 才完整兑现。
5. **盘面反推叙事是循环论证。** 看到板块涨就编一个理由，等于没做研究。

---

## 1. 第一步永远是数据边界

报告开头必须写：

| 项 | 必须写清 |
|---|---|
| 数据截止日 | EOD 到哪一天 |
| 是否盘中 | 若盘中，明确「今天无 EOD，本节为隔夜推演」 |
| 时间戳口径 | A 股 T 日 15:00 收盘 ≈ 美东 T 日凌晨 02:00 |

**禁止**用 EOD 数据说「今天」。盘中只能写「隔夜发生了 X，今天开盘可能交易 Y」，并标为推断。

---

## 2. 四层结构（按序，不可跳层）

### 第 1 层 · 盘面事实（只出数，不解释）

必取字段：

| 维度 | 表 | 用途 |
|---|---|---|
| 全市场涨跌家数 / 平均涨幅 | `daily_kline_adj` | 普涨还是结构 |
| 宽基梯度（全指/300/500/1000/创业板/科创50） | `index_daily_kline` | 大小盘与成长价值切换 |
| 红利 / 自由现金流 / 价值类 | 同上 | 是否风险偏好切换 |
| 行业 / 主题 / 策略指数涨幅榜前 20、跌幅榜前 10 | `index_daily_kline` + `stock_index`（名称） | 主线识别 |
| 行业分组健康分（9 组） | `market_health_sector_daily` | 强弱分组 |
| 板块轮动（5 日 overlap / spearman） | `market_rotation_daily` | 是否换赛道 |
| 资金流（mfv_10/65/250d） | `index_capital_flow_daily` | 钱在往哪去 |
| 龙虎榜 / 大宗 / 两融 | `daily_review_lhb` / `_block_trade` / `_margin` | 游资与杠杆 |
| 个股 RS 分布 | `stock_rs_daily` | 强弱扩散 |

输出时必须带**样本量**（如「5,649 只，涨 4,732 / 跌 786，平均 +2.81%」）。

### 第 2 层 · 隔夜外部（带时间戳）

| 资产 | 用途 |
|---|---|
| 美股三大指数 + **费城半导体** | A 股科技链的隔日锚 |
| 布伦特 / WTI | 石化、化工、交运、航空 |
| COMEX 黄金 | 黄金股、有色 |
| 美元指数 / 美债 10Y | 外资、成长股估值 |
| 纳斯达克中国金龙 | 中概与港股映射 |

每条写清「美东 X 日夜间」。**A 股 T 日只反应到 T-1 夜间的收盘值；T 日夜间的变化要到 T+1 日才生效。**

### 第 3 层 · 事件层

`web_search` 取政策 / 地缘 / 财报 / 产业新闻。每条附**来源 + 日期**。
事件必须可观测、有出处，不许写「市场传闻」。

### 第 4 层 · 传导链与符号核对（核心）

每条主线写成六列，禁止省略：

| 字段 | 要求 |
|---|---|
| **触发事件** | 可观测，带时间戳 |
| **一级传导** | 成本 / 需求 / 风险偏好 / 汇率 / 利率 / 政策，选其一为主 |
| **二级分化** | 同一行业内谁受益、谁受损 |
| **预期符号** | 明确写「A 应涨、B 应跌」 |
| **实际** | 当日该板块/个股的涨跌 |
| **判定** | 成立 / 不成立 / 待验证 |

**符号错了就是错了。** 记入 §6 反例库，并写清「为什么实际方向相反」。

## 3. 行业与主题传导链库

用法：按当日事件查表，取出候选链，逐条核对符号。
**表里给的是「先验方向」，不是结论**——见 §6 反例：同一条链在不同阶段符号会反转。

### 3.1 化工（最典型的分化行业）

**核心不是「化工涨不涨」，是「哪条原料路线受益」。**

| 原料路线 | 成本锚 | 油价下跌时 | 代表（**须按年报核实原料结构**） |
|---|---|---|---|
| 油头 | 石脑油 / PX | 成本降，**但若产品价格同步下跌则价差可能收窄** | 恒力石化、荣盛石化、恒逸石化、中国石化 |
| 气头 | 乙烷 / 天然气 | 与油价脱钩，**不受益** | 卫星化学（乙烷裂解） |
| 煤头 | 动力煤 / 无烟煤 | 与油价脱钩，看煤价 | 华鲁恒升、宝丰能源 |

**关键分化变量**：

1. **价差方向** = 产品价格 − 原料价格。油价崩时若下游需求弱，产品价格跌得更快 → 价差收窄 → 油头也跌。
2. **库存损益**：高库存 + 产品价格下跌 = 跌价损失，直接吃利润。
3. **原料自给率**：一体化的公司成本传导有滞后，短期反而吃亏。

**可验证指标**：布伦特、石脑油 CFR 日本、PX-石脑油价差、乙烯-石脑油价差、纯苯、MDI 挂牌价。
**常见误判**：把「成本下降」直接当「利润上升」，忽略产品价格同步下跌。

### 3.2 光伏 / 新能源

| 驱动 | 传导 | 预期符号 |
|---|---|---|
| 海外绿能政策友好（如美国民主党执政） | 装机预期上修 | 组件、逆变器、支架涨 |
| 财报显示亏损收窄 / 转盈 | 底部确认 | 全链条涨，二线弹性更大 |
| **财报空白期** | 只有预期、无证伪数据 | 反弹可持续到下一份财报前 |
| 产能出清政策 | 供给收缩 | 龙头涨、落后产能出清 |
| 硅料价格反弹 | 成本上升 | 组件承压、硅料涨 |

**「空白期」是本行业特有的交易逻辑**：Q3 财报公布后到 Q4 财报前约 3 个月，预期无法被证伪，资金愿意给估值。
**失效点**：硅料价格重新下跌、或龙头宣布扩产。

**可验证指标**：硅料/硅片/电池片/组件价格、开工率、出口数据、招标量。

### 3.3 AI 产业链

**分层看，不能整体看。**

| 层 | 驱动 | 预期符号 | 常见误判 |
|---|---|---|---|
| 算力硬件（光模块/PCB/服务器） | 北美云厂资本开支 | 上修 → 涨 | 把「AI 需求好」当成所有环节都好 |
| 存储（HBM/DRAM） | 涨价周期 | 涨价 → 涨 | 存储涨价反噬下游手机/PC 毛利 |
| 芯片设计 | 终端需求 + 制程 | 费半涨 → A 股补涨 | 隔日补涨常常只有 1~2 天 |
| 应用/软件 | 商业化落地 | 滞后于硬件 | 用软件估值买硬件 |
| 电力设备（AIDC 供电） | 数据中心装机 | 独立于芯片周期 | 与算力硬件混为一谈 |

**A 股特有**：**隔日补涨**。美东 T-1 夜费半涨 → A 股 T 日半导体链补涨，幅度常放大（A 股弹性 > 美股）。
**核对方式**：费半 T-1 涨跌幅 vs A 股 T 日半导体指数涨跌幅。
**失效点**：费半涨但 A 股不跟 → 说明国内有自己的定价（政策/国产替代/业绩）。

### 3.4 黄金 / 有色

| 驱动 | 传导 | 预期符号 |
|---|---|---|
| 美元走弱 / 实际利率下行 | 金价上行 | 黄金股涨，弹性 > 金价 |
| 地缘风险下降 | 避险需求降 | **金价可能跌**（与「风险偏好上升」同向） |
| 政治僵局 → 财政扩张受限 | 美元弱、通胀预期降 | 金价涨（这一条与上一条冲突，需分辨主因） |
| 铜：全球需求 | 制造业 PMI、电网投资 | 铜股涨 |

**黄金最容易被讲错的因果**：走弱美元 → 金涨（货币属性）；战争结束 → 金跌（避险属性）。
**两个方向同时存在时，看当日美元指数与美债实际利率，而不是看新闻标题。**

### 3.5 半导体 / 设备材料

| 驱动 | 预期符号 |
|---|---|
| 国产替代政策 / 大基金 | 设备材料 > 设计 |
| 海外制裁收紧 | 国产替代涨、依赖进口的跌 |
| 存储涨价 | 存储链涨、下游终端承压 |
| 费半隔夜 | A 股次日补涨（见 3.3） |

### 3.6 煤炭 / 电力 / 公用

| 驱动 | 预期符号 |
|---|---|
| 油价崩 | 煤炭替代需求下降 → 煤跌 |
| 电价市场化 | 火电利润扩张 → 火电涨 |
| 绿电装机 | 绿电运营商涨、火电承压 |
| 高股息避险需求 | 与红利指数同向 |

### 3.7 消费 / 银行 / 地产

| 驱动 | 预期符号 |
|---|---|
| 风险偏好上升（成长占优） | **消费、银行、红利相对跑输**（资金搬家） |
| 降息 / 降准 | 银行息差承压、地产受益 |
| 财政刺激 | 消费、地产链受益 |
| 政治僵局 → 财政受限 | 内需板块承压 |

**「普涨日里的滞涨」是重要信号**：普涨日某板块 0% 或下跌，等于资金在主动撤离，比单独下跌更有信息量。

### 3.8 军工

| 驱动 | 预期符号 |
|---|---|
| 战争预期升温 | 涨 |
| 战争预期降温（如他国政局变化） | **跌** |
| 国内订单 / 阅兵 / 预算 | 独立于海外 |

### 3.9 医药

| 驱动 | 预期符号 |
|---|---|
| 集采 | 仿制药跌、创新药影响小 |
| 海外授权（BD） | 创新药涨 |
| 美债利率下行 | 创新药（长久期资产）受益 |

### 3.10 券商

| 驱动 | 预期符号 |
|---|---|
| 成交额放大 | 涨（β 属性） |
| 资本市场政策 | 涨 |
| 普涨但券商滞涨 | 说明是结构性行情，非全面牛市 |

## 4. 符号核对表（每条主线必填）

| 主线 | 预期涨 | 预期跌 | 实际 | 判定 |
|---|---|---|---|---|
| 例：油价崩 | 油头化工 | 石油开采 | 石油 −2.71%、万华 −1.16% | **不成立**（见反例 1） |
| 例：绿能受重视 | 光伏 | 煤炭 | 光伏 +2~7%、煤炭 0% | 成立 |
| 例：金价破 4000 | 黄金股 | — | SSH黄金股票 +9.00% | 成立 |

**判定只用当日数据，不许用「后来涨了」补。**

---

## 5. 输出格式（当日简报）

1. **一句话结论**（≤40 字）
2. **数据边界**（截止日 / 是否盘中 / 时区）
3. **盘面事实表**（宽基梯度 + 涨跌家数 + 涨幅榜前 10 + 跌幅榜前 5）
4. **隔夜外部表**（六大资产，带美东日期）
5. **主线 3~5 条**，每条按 §2 第 4 层六列写
6. **符号核对结论**：成立几条、不成立几条
7. **待验证清单**：今天开盘后看什么能证伪
8. **数据缺口**（本次缺什么，影响哪条判断）

## 6. 反例库（先验方向被证伪的记录）

### 反例 1 · 「油价崩 → 油头化工受益」在需求走弱时符号反转

**日期**：2026-11-04（A 股）
**事件**：美国中期选举民主党横扫 → 战争预期结束 → 布伦特盘中暴跌 10%
**先验符号**：油价崩 → 油头成本降 → 油头化工涨
**实际**：

| 个股 | 原料路线 | 11-04 |
|---|---|---|
| 中国石油 | 油气开采 | **−2.71%** |
| 荣盛石化 | 油头（PX/石脑油） | **−1.98%** |
| 恒力石化 | 油头 | −1.33% |
| 万华化学 | 煤头+油头混合 | −1.16% |
| 中国石化 | 油头 | −0.86% |
| 恒逸石化 | 油头 | −0.47% |
| 卫星化学 | 气头（乙烷） | +0.51% |
| 桐昆股份 | 油头（聚酯） | +4.23% |

**结论**：油头**全线下跌**，气头微涨，先验符号不成立。
**机制推断**：当日市场交易的是「战争结束 → 需求走弱 + 产品价格下跌 → 价差收窄 + 库存跌价」，
成本利好被需求利空盖过。桐昆逆势 +4.23% 说明真正的驱动是聚酯自身景气，不是油价。
**教训**：**成本端利好 ≠ 利润利好。必须同时看产品价格方向。**
**可复用的判据**：油价单日跌幅 >5% 时，先查下游产品价格是否同步下跌；同步下跌则油头不涨。

## 7. 记录与迭代（让 skill 变成资产）

每日输出后，把「事件 → 预期符号 → 实际」追加到一张表（建议落 `docs/market-logic/events.csv`）：

```
date,event,chain,expect_up,expect_down,actual_up,actual_down,verdict
```

攒够样本后可以回答：**同一类事件历史上符号稳定的比例是多少**。
这是本 skill 唯一可能从「叙事」变成「统计」的路径。
阈值建议：符号稳定率 < 70% 的链，不得作为交易依据。

## 9. 已知数据缺口（当前口径）

| 缺口 | 影响 | 补法 |
|---|---|---|
| **只有 EOD，无盘中** | 「当日」只能到上一收盘日 | 接东财/新浪实时行情 |
| 商品日频序列未入库 | 油价/金价/铜价/美元/美债全靠新闻文字 | akshare 期货与外汇接口 |
| 事件未结构化落库 | 无法回测「事件→板块」 | §7 的 CSV 起步 |
| 概念板块缺失 | 游资概念（算力租赁、机器人）看不到 | 东财概念板块接口 |
| 涨停梯队/连板/封板率 | 情绪温度只能间接推断 | 需补涨停板数据 |

## 10. 与其他技能的关系

| 技能 | 分工 |
|---|---|
| `index-research` | 单只指数的长期研究，不是当日 |
| `stock-health-report` | 个股体检，不是当日 |
