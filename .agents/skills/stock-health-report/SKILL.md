# 个股健康体检报告 Skill

## 0. 定位与铁律

本 skill 把"个股尽调"组织成一条**有主持人的决策流水线**：机器先定盘 → 九大师单向投票 → 主持人终裁输出动作。
**铁律（违反即不合格）**：
1. **裁决协议是输出结构**：必须落到"五档评级 + 动作清单（建仓区/止损/目标/失效条件/下次体检触发点）"，不允许只给一堆平行观点。
2. **九大师每人必须投"买/等/回避"单向票**（奇数 9 人，结构性避免平局）+ 一句基于数据的理由。禁止自由发挥长文。观点不同可以，但都要表态。
   **九个视角各管一件事，不要串味**：欧奈尔看买点与CANSLIM、威科夫看吸筹派发、利弗莫尔看趋势关键点、段永平看生意与能力圈、巴菲特看护城河与资本配置、芒格看逆向风险、索罗斯看反身性周期、**Oliver Kell 只看价格行为（不看基本面）**、**Mauboussin 只反推价格隐含预期（不判公司好坏）**。
3. **数据不可编造**：确定性数据必须来自 `scripts/collect_data.py`（本地库）或本机 API；外部信息（行业/公告/业务占比/前瞻）用 web_search 且标注来源。缺的数据明说"未获取"，不得伪装。
4. **理解优先**：写不出"一句话业务定位 + 收入/毛利占比"之前，不许进入估值与投票环节（能力圈闸门）。
5. **红涨绿跌**：HTML 中涨/买/看好=#ef4444 红系，跌/卖/风险=#10b981 绿系。

## 1. 工作流（严格按序）

### 步骤 0 · 市场闸门
查本地 market-scan 数据：大盘趋势（追盘日/抛盘日）、风险级别。输出一行环境判断（顺风/逆风/中性），并说明它对仓位的影响。数据源：`http://localhost:8788/api/market-scan` 系 API。

### 步骤 1 · 数据拉取
运行：`python scripts/collect_data.py <CODE> --detail`（detail 模式含均线全系/MACD/KDJ/RSI/BOLL/量能/支撑压力/近15日K线 + 财务评估六卡实际输出）。
然后 web_search 补齐外部信息：行业最新动态、近期公告/财报要点、业务分部数据、可比公司、有无重大新闻。搜索不超过 4 次，聚焦"业务结构 + 行业格局 + 边际变化"。

### 步骤 2 · 否决筛查（先确认不会死）
- ST/退市/上市状态（快照 §2）、质押爆仓风险、重大造假/失信历史（搜索确认）
- **致命项命中 → 直接输出"回避"报告**，不再做后续层（可简要说明否决理由）。

### 步骤 3 · 认识它（理解层，硬门槛）
- **一句话业务定位**：这公司靠什么赚钱（≤30 字，如"成本曲线最左端的 MDI 全球寡头，聚氨酯-石化-精细三链一体"）。写不出 = 能力圈外 → 输出"回避/看不懂不投"。
- **收入与毛利结构占比**（按业务分部，近 2 年变化——哪块在长大/萎缩）
- **商业模式类型**：周期制造/成长消费/收租平台/项目制等 + 盈利稳定性特征
- **管理层资本配置历史**：近 5 年资本开支方向、分红/回购记录、ROIC 趋势（快照 §6 年度财务可支撑）

### 步骤 4 · 行业卡
- 行业生命周期与景气位置（周期复苏中段/顶部/底部？）
- 竞争格局与集中度：公司在食物链位置（老大/老二/边缘），护城河来源
- 行业驱动因素与 12-24 个月前瞻（供需/价格/政策/技术）

### 步骤 5 · 评估它（财务验证 + 行业校准）
- 用快照 §5/§6：营收/净利/毛利率的季度与年度趋势、TTM 滚动同比、**二阶导（加速度）**——加速/减速？
- 财务健康：负债率/有息/周转，**必须对照行业特征校准**（同一阈值不适用所有行业；应收周转高不一定是坏事要看行业）
- 盈利质量（comps/quality 卡）：扣非占比、现金含量、FCF 与净利缺口（应收存货扩张要警惕）

### 步骤 6 · 定价它（估值构成拆解，禁止只报分位）
- 多周期分位：快照 §4 的 3/5/10 年分位直接引用（PE/PB/PS/股息率）
- **估值构成推算（核心）**：当前价格隐含了什么预期？方法：
  - 反推公允 PE：无风险利率(≈1.7%) + 股权风险溢价(≈5%) → 公允 PE ≈ 15x；与当前对比
  - 隐含增长：当前 PE ÷ (1/公允基准) 意味着市场定价了多少增长/周期恢复
  - 周期位置修正：周期股盈利低谷的"低 PE"可能是陷阱（盈利顶给最低 PE），要说明当前 PE 对应盈利的周期位置
- 一句话定价结论："现价已包含 XX 预期，贵/合理/便宜是因为 XX"

### 步骤 6.5 · 预期反推（Mauboussin 的证据基础）

**目的：不判断贵/便宜，而是反推「当前价格已经假设了什么」，再与基本面趋势对照。**

**方法一：反推隐含增长率**

隐含增长率 g = WACC − 1/PE

用 WACC ≈ 10%（无风险 1.7% + 股权风险溢价 5% + 周期/小盘溢价约 3%）：
- PE = 12.86 → 1/PE = 7.78% → g = 10% − 7.78% = 2.2%/年
- 若自身近 3 年净利 CAGR 为 −8%，则价格隐含的 +2.2% 增长明显偏乐观 → 偏回避

**方法二：与自身历史对照判方向**

| 对照 | 含义 | 票 |
| :--- | :--- | :--- |
| 隐含 g < 自身近 3 年 CAGR | 预期偏低 | 买 |
| 隐含 g ≈ 自身 CAGR（±2pp） | 预期已定价 | 等 |
| 隐含 g > 自身 CAGR | 预期偏高 | 回避 |

**方法三：ROIC vs WACC（增长是否创造价值）**

价值创造 = ROIC − WACC

- ROIC > WACC：增长创造价值，可给估值溢价
- ROIC < WACC：增长毁灭价值，增长率越高越该压低估值

**数据来源**：PE 取快照 §4；近 3 年 CAGR 取 §6 年度财务；
ROIC 可用 净利 /（有息负债 + 股东权益）粗算，**算不出时明说「未获取」，不得臆造**。

**必须输出**：隐含 g、自身 3 年 CAGR、二者差（pp）、ROIC vs WACC 判断、一句话结论（预期偏高／合理／偏低）。


### 步骤 7 · 择时它（技术面）
- 快照 §1（股价结构/均线/量额）+ §7（RS）+ §8（缠论/MW 信号）
- 趋势状态：多头/空头/震荡 + 距关键位
- 明确：买点区域/止损位/上方压力（用 collect_data 数据 + pattern-scan 信号，不要凭空）

### 步骤 7.5 · CPA 九阶段判定细则（Oliver Kell 的证据基础）

**这一步只产出「当前处于哪一阶段 + 证据」，投票在步骤 9。**

| 阶段 | 判定标准（须全部满足） |
| :--- | :--- |
| **基部构筑** | 价格在 60 日内振幅 ≤ 25%；EMA10 与 EMA20 纠缠（间距 < 2%）且方向走平；量能萎缩至 20 日均量的 60~80% |
| **基部突破** | 收盘价 > 基部上沿（近 20 日最高收盘）× 1.005；**当日量 ≥ 20 日均量 × 1.5**；EMA10 > EMA20 |
| **上升趋势回踩** | 价在 EMA20 上方；EMA10 > EMA20 > EMA50；回踩至 EMA10 或 EMA20 附近（±2%）且缩量 |
| **EMA 回踩买点** | 上一项成立 + 回踩日量 ≤ 20 日均量 × 0.8 + 次日收复 EMA10 |
| **上升趋势延伸** | EMA 多头排列 + 价距 EMA20 乖离 > 2×ATR（追高风险区） |
| **衰竭延伸** | 上升趋势中出现：连续 3 日收盘远离 EMA10、量能背离（价新高量不新高）、RSI 顶背离 |
| **楔形突破** | 收敛三角形/楔形整理末端，突破方向决定多空 |
| **派发** | 高位放量滞涨；单日跌幅 > 5% 且量 > 20 日均量 × 1.5（抛盘日）；EMA10 下穿 EMA20 |
| **反转延伸** | EMA 空头排列 + 价在 EMA20 下方 + 反弹缩量 |
| **破位** | 收盘跌破基部下沿或前低，**无需确认**（见下条） |

**铁律：买点与卖点的不对称**

> **买点必须次日确认**（突破日收盘站上关键位，次日收盘仍在关键位上方才算成立）；
> **破位不需要确认**（跌破关键位当日即成立）。
> 这个不对称是刻意的——**错了要立刻走，对了可以等一下**。

**失效判定（CPA 的核心就是「基部失败 = 退出」）**

出现任一即视为 CPA 买点失效：
- 收盘跌回突破位下方
- EMA20 失守且 3 日内未收复
- 突破后量能持续萎缩至 20 日均量 80% 以下

**必须输出**：当前阶段、支撑位（EMA10/EMA20/基部下沿）、压力位、失效位、风险收益比（到压力位涨幅 ÷ 到失效位跌幅）。**比值 < 2 时 Oliver Kell 应投「等」或「回避」。**

### 步骤 8 · 情景前瞻
给 3 情景（基准/乐观/悲观），各含：关键假设 → 盈利路径 → 对应价区。禁止只给 1 个点预测。最后给"证伪条件"（什么信号出现 = 我错了，1-3 条）。

### 步骤 9 · 九大师单向投票（奇数票制）
每人在一行内给：**票（买/等/回避）+ 一句理由**。禁止并列表述。
- 欧奈尔（技术买点/机构吸筹/CANSLIM）：看买点质量、相对强度、量价、机构行为
- 威科夫（市场结构）：判断吸筹/派发/拉升/下跌阶段 + 量价验证
- 利弗莫尔（趋势/关键点）：趋势是否成立、关键点突破/失效
- 段永平（商业模式/本分）：生意看得懂吗、管理层本分吗、能力圈
- 巴菲特（护城河/估值/资本配置）：护城河宽窄、估值安全边际、资本配置理性
- 芒格（逆向/风险/心智）：最大的风险是什么、我可能错在哪、有什么致命缺陷
- 索罗斯（反身性/周期）：趋势自我强化的阶段（早期/中段/后段）、共识叙事是否已被价格透支、反身性转向风险
- **Oliver Kell（CPA 价格行为循环）**：**只看价格行为，不看基本面**。九阶段定位（反转延伸/楔形突破/EMA回踩/基部突破/衰竭延伸/破位/基部构筑/上升趋势回踩/派发）；必须回答：现价处于哪一阶段、EMA10 与 EMA20 关系、量能是否配合、风险收益比数值、买点是否需要次日确认
- **Michael Mauboussin（预期投资 / 价格反推）**：**只反推价格隐含了什么，不判断公司好坏**。必答：当前价格隐含的增长率/利润率是多少？该隐含值 vs 基本面趋势是偏高还是偏低？ROIC 是否高于 WACC（增长在创造还是毁灭价值）？市场预期正在往哪个方向修正

### 步骤 10 · 主持人裁决
```
① 机器分汇总：CANSLIM 分 + 技术分 + 财务质量 + 估值带（客观先定盘）
② 七票清点：买 n / 等 n / 回避 n（技术组 vs 价值组 vs 周期派分歧要显式点出并解释）
③ 否决检查：步骤 2/8 有致命项 → 直接回避
④ 终裁：五档评级（强烈推荐/谨慎推荐/中性/观望/回避）
     + 动作清单（建仓区/止损/目标位/失效条件/下次体检触发点）
     + 风险提示 + 数据来源与缺口标注 + 时间戳
```
裁决规则：机器分是底线（基本面差不给高评级）；大师票决定上限（共识买入才可强烈推荐）；
分歧时主持人（你）基于步骤 3-8 的证据裁决并写明理由。

**九票制下不可能平局（9 为奇数），但要警惕「5:4 的伪共识」**：
若赞成票只有 5 张且其中 ≥2 张来自同流派（如三位技术派同票），
主持人必须点出「这是技术派共识，不是全局共识」，并相应下调评级档位。

**流派分组（用于识别伪共识）：**

| 流派 | 成员 |
| :--- | :--- |
| 技术派 | 欧奈尔、威科夫、利弗莫尔、**Oliver Kell** |
| 价值派 | 段永平、巴菲特、**Mauboussin** |
| 风险/周期派 | 芒格、索罗斯 |

并把 `/api/market-health` 的 rating 单独列出来作为补充判断。**

### 3.2.1 分部业绩比较方法论（踩过的坑，必须按此做）

**反面教材（本发明过）：** 看到万华石化板块占收入 40%、毛利率仅 6.8%，
就下结论「增长质量低、靠低毛利业务撑收入」。**这个判断是错的。**

**正确做法：四步，缺一步就会得出反向结论。**

#### 第一步：认清披露节奏——分部数据只有半年报和年报

A 股季报**不披露分部构成**。营收构成 API 返回的期次实测为：

```
2026-06-29 (半年报)  2025-12-30 (年报)  2025-06-29 (半年报)  2024-12-30 (年报) …
```

**所以在写「Q3 某板块如何」之前先确认：Q3 有没有分部数据。没有就是没有，
不要从合计口径硬推分部结论，也不要说「数据拿不到」——是披露规则如此。**

**合计口径只能做交叉验证，不能替代分部：**
若某季合计毛利率低于上一个半年报的合计毛利率，说明该季整体毛利在回落，
此时「某板块该季改善更明显」这类推断需要证据，不能默认成立。

#### 第二步：必须同时看「毛利率水平」和「毛利率变化」

| 只看水平（错） | 加上变化（对） |
|---|---|
| 石化毛利率 6.8%，最低 → 「拖累项」 | 石化毛利率从 **−0.4% 到 +6.8%（+7.2pp）**，改善幅度全场最大 |

**周期股的板块毛利率长期在低位，恰恰说明它处在周期底部、弹性最大。
用「水平低」否定它，等于在最该关注的时候忽略它。**

#### 第三步：算「毛利额增量贡献」，这才是利润的真实来源

毛利率变化容易被小基数放大，必须换算成**绝对额增量**再排序：

```
毛利额 = 收入 × 毛利率
毛利额增量 = 本期毛利额 − 基期毛利额
贡献占比 = 该板块增量 ÷ 各板块增量之和
```

**万华实测（2025H1 → 2026H1）：**

| 板块 | 收入同比 | 毛利率变动 | 毛利额增量 | 贡献占比 |
|---|---|---|---|---|
| **石化** | +36.7% | **+7.2pp** | **+33.9 亿** | **44.2%** |
| 聚氨酯 | +21.9% | +1.4pp | +27.0 亿 | 35.3% |
| 精细化学品 | +44.3% | +6.7pp | +21.8 亿 | 28.4% |
| 其他 | +15.2% | −6.5pp | −6.0 亿 | −7.8% |
| 合计 | +29.9% | +3.1pp | **+76.7 亿** | 100% |

**结论完全反转：石化贡献了毛利额增量的 44.2%，是第一贡献者，不是拖累项。**

#### 第四步：一体化企业的分部利润率不能孤立解读

**垂直一体化公司的上游板块（石化、原料）常以内部转移价供应下游（聚氨酯），
利润在下游体现、成本在上游承担。**

因此：
- **上游板块毛利率低 ≠ 该板块无价值**，它的价值体现在「保证原料自给 + 降低整体成本」
- 这部分协同收益**无法从财报分部数据直接量化**，只能定性说明，且**必须标明「定性判断，不可量化」**
- 判断一体化企业，看的是**合计毛利率趋势**和**各环节是否都在改善**，而不是单看某一段

#### 输出要求（写进报告的业务画像一节）

必须给一张表，列为：
`板块 | 本期收入 | 基期收入 | 收入同比 | 基期毛利率 | 本期毛利率 | 毛利率变动 | 毛利额增量 | 贡献占比`

并配一句结论：**哪个板块是毛利额增量的第一贡献者，哪个是唯一恶化项。**

**禁止只列「收入占比 + 毛利率」两列就下判断。**

## 4. 输出长度纪律

- 终裁卡 + 投票表是硬结构；其余各步精炼，总报告 HTML 控制在 30-50KB
- 证据说话：每个判断带数据（具体数字或信号），禁止"基本面良好"式空话
- 诚实>好看：不确定处明说，与数据矛盾的直觉要标注"与数据不一致，存疑"
- <b>④财务评估与⑥择时是报告的"肉"，禁止简表</b>：
  - ④ 财务评估必含：4.1 季度盈利趋势近 8 季明细表（营收/净利/毛利率/同比，标注拐点季）→ 4.2 年度轨迹表（近 6-10 年 + TTM，标注周期位置与距前顶空间）→ 4.3 六卡实际输出（DCF 目标价+敏感性带 / comps 中位与可比明细 / model 预测标注"机械外推"局限 / quality 警示逐条 / cashflow 年度 OCF-FCF）——quality/cashflow 异常必须上升为风险提示
  - ⑥ 择时必含：6.1 均线系统全表（MA5~MA250 数值+现价相对位置+排列判断，MA120/250 压制要显式指出，禁笼统"多头"）→ 6.2 指标读数（MACD/KDJ/RSI6-12-24/BOLL）→ 6.3 量能与资金（量比/近10日涨跌量额/两融）→ 6.4 支撑压力（60/250日高低+斐波那契+BOLL+均线粘合位）→ 6.5 个股 vs 行业 RS 对比（差距显式）+ 缠论连续两日信号（翻转要警示）→ 6.6 近期 K 线/价格行为表 → 择时小结（关键位+两种情景路径）
  - <b>行业口径纪律（踩过坑）</b>：行业归属用申万（stock_sw_industry，如万华/卫星同为"化工"）；行业/产业 RS 是另一套中证 L2 产业分类（如 800材料/油气产业）——报告必须分开标注两套口径，禁止把"产业指数 RS"写成"化工行业 RS"，也禁止据此断言两股属不同行业
  - ④⑥ 两节合计应占正文 40%+，每个结论带具体数字
