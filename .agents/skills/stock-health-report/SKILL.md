# 个股健康体检报告 Skill

## 0. 定位与铁律

本 skill 把"个股尽调"组织成一条**有主持人的决策流水线**：机器先定盘 → 六大师单向投票 → 主持人终裁输出动作。
**铁律（违反即不合格）**：
1. **裁决协议是输出结构**：必须落到"五档评级 + 动作清单（建仓区/止损/目标/失效条件/下次体检触发点）"，不允许只给一堆平行观点。
2. **六大师每人必须投"买/等/回避"单向票** + 一句基于数据的理由。禁止自由发挥长文。观点不同可以，但都要表态。
3. **数据不可编造**：确定性数据必须来自 `scripts/collect_data.py`（本地库）或本机 API；外部信息（行业/公告/业务占比/前瞻）用 web_search 且标注来源。缺的数据明说"未获取"，不得伪装。
4. **理解优先**：写不出"一句话业务定位 + 收入/毛利占比"之前，不许进入估值与投票环节（能力圈闸门）。
5. **红涨绿跌**：HTML 中涨/买/看好=#ef4444 红系，跌/卖/风险=#10b981 绿系。

## 1. 工作流（严格按序）

### 步骤 0 · 市场闸门
查本地 market-scan 数据：大盘趋势（追盘日/抛盘日）、风险级别。输出一行环境判断（顺风/逆风/中性），并说明它对仓位的影响。数据源：`http://localhost:8788/api/market-scan` 系 API。

### 步骤 1 · 数据拉取
运行：`python scripts/collect_data.py <CODE> --detail`（detail 模式含均线全系/MACD/KDJ/RSI/BOLL/量能/支撑压力/近15日K线 + 财务评估六卡实际输出）。
然后 web_search 补齐外部信息：行业最新动态、近期公告/财报要点、业务分部数据、可比公司、有无重大新闻。搜索不超过 4 次，聚焦"业务结构 + 行业格局 + 边际变化"。

### 步骤 2 · 否决筛查（先确认不会死）
- ST/退市/上市状态（快照 §2）、质押爆仓风险、重大造假/失信历史（搜索确认）
- **致命项命中 → 直接输出"回避"报告**，不再做后续层（可简要说明否决理由）。

### 步骤 3 · 认识它（理解层，硬门槛）
- **一句话业务定位**：这公司靠什么赚钱（≤30 字，如"成本曲线最左端的 MDI 全球寡头，聚氨酯-石化-精细三链一体"）。写不出 = 能力圈外 → 输出"回避/看不懂不投"。
- **收入与毛利结构占比**（按业务分部，近 2 年变化——哪块在长大/萎缩）
- **商业模式类型**：周期制造/成长消费/收租平台/项目制等 + 盈利稳定性特征
- **管理层资本配置历史**：近 5 年资本开支方向、分红/回购记录、ROIC 趋势（快照 §6 年度财务可支撑）

### 步骤 4 · 行业卡
- 行业生命周期与景气位置（周期复苏中段/顶部/底部？）
- 竞争格局与集中度：公司在食物链位置（老大/老二/边缘），护城河来源
- 行业驱动因素与 12-24 个月前瞻（供需/价格/政策/技术）

### 步骤 5 · 评估它（财务验证 + 行业校准）
- 用快照 §5/§6：营收/净利/毛利率的季度与年度趋势、TTM 滚动同比、**二阶导（加速度）**——加速/减速？
- 财务健康：负债率/有息/周转，**必须对照行业特征校准**（同一阈值不适用所有行业；应收周转高不一定是坏事要看行业）
- 盈利质量（comps/quality 卡）：扣非占比、现金含量、FCF 与净利缺口（应收存货扩张要警惕）

### 步骤 6 · 定价它（估值构成拆解，禁止只报分位）
- 多周期分位：快照 §4 的 3/5/10 年分位直接引用（PE/PB/PS/股息率）
- **估值构成推算（核心）**：当前价格隐含了什么预期？方法：
  - 反推公允 PE：无风险利率(≈1.7%) + 股权风险溢价(≈5%) → 公允 PE ≈ 15x；与当前对比
  - 隐含增长：当前 PE ÷ (1/公允基准) 意味着市场定价了多少增长/周期恢复
  - 周期位置修正：周期股盈利低谷的"低 PE"可能是陷阱（盈利顶给最低 PE），要说明当前 PE 对应盈利的周期位置
- 一句话定价结论："现价已包含 XX 预期，贵/合理/便宜是因为 XX"

### 步骤 7 · 择时它（技术面）
- 快照 §1（股价结构/均线/量额）+ §7（RS）+ §8（缠论/MW 信号）
- 趋势状态：多头/空头/震荡 + 距关键位
- 明确：买点区域/止损位/上方压力（用 collect_data 数据 + pattern-scan 信号，不要凭空）

### 步骤 8 · 情景前瞻
给 3 情景（基准/乐观/悲观），各含：关键假设 → 盈利路径 → 对应价区。禁止只给 1 个点预测。最后给"证伪条件"（什么信号出现 = 我错了，1-3 条）。

### 步骤 9 · 六大师单向投票
每人在一行内给：**票（买/等/回避）+ 一句理由**。禁止并列表述。
- 欧奈尔（技术买点/机构吸筹/CANSLIM）：看买点质量、相对强度、量价、机构行为
- 威科夫（市场结构）：判断吸筹/派发/拉升/下跌阶段 + 量价验证
- 利弗莫尔（趋势/关键点）：趋势是否成立、关键点突破/失效
- 段永平（商业模式/本分）：生意看得懂吗、管理层本分吗、能力圈
- 巴菲特（护城河/估值/资本配置）：护城河宽窄、估值安全边际、资本配置理性
- 芒格（逆向/风险/心智）：最大的风险是什么、我可能错在哪、有什么致命缺陷

### 步骤 10 · 主持人裁决
```
① 机器分汇总：CANSLIM 分 + 技术分 + 财务质量 + 估值带（客观先定盘）
② 六票清点：买 n / 等 n / 回避 n（技术组 vs 价值组分歧要显式点出并解释）
③ 否决检查：步骤 2/8 有致命项 → 直接回避
④ 终裁：五档评级（强烈推荐/谨慎推荐/中性/观望/回避）
     + 动作清单（建仓区/止损/目标位/失效条件/下次体检触发点）
     + 风险提示 + 数据来源与缺口标注 + 时间戳
```
裁决规则：机器分是底线（基本面差不给高评级）；大师票决定上限（共识买入才可强烈推荐）；分歧时主持人（你）基于步骤 3-8 的证据裁决并写明理由。

## 2. HTML 报告规范

- 路径：`D:\hanako\investment-system\web\stock-health\reports\{CODE}_{YYYYMMDD}.html`（自建目录）
- 引用共享 CSS：`<link rel="stylesheet" href="../../shared/css/theme.css">`（base/xhs-cards/components 视需要），或页面内嵌 hanako-glass 最小变量集
- 章节顺序：① 终裁卡（最顶，含评级+动作清单）② 市场闸门 ③ 认识它（业务画像/占比）④ 行业卡 ⑤ 财务评估 ⑥ 定价（分位+构成拆解）⑦ 择时（技术）⑧ 情景与证伪 ⑨ 六大师投票表 ⑩ 风险与数据源
- 终裁卡放最顶是刻意的：读者先看到"结论与动作"，再向下看证据
- 红涨绿跌：涨/买/看好=#ef4444，跌/卖/风险=#10b981（硬编码，不用 CSS 变量）
- 表格紧凑、数字两位小数、长文分段克制

## 4. 输出长度纪律

- 终裁卡 + 投票表是硬结构；其余各步精炼，总报告 HTML 控制在 30-50KB
- 证据说话：每个判断带数据（具体数字或信号），禁止"基本面良好"式空话
- 诚实>好看：不确定处明说，与数据矛盾的直觉要标注"与数据不一致，存疑"
- <b>④财务评估与⑥择时是报告的"肉"，禁止简表</b>：
  - ④ 财务评估必含：4.1 季度盈利趋势近 8 季明细表（营收/净利/毛利率/同比，标注拐点季）→ 4.2 年度轨迹表（近 6-10 年 + TTM，标注周期位置与距前顶空间）→ 4.3 六卡实际输出（DCF 目标价+敏感性带 / comps 中位与可比明细 / model 预测标注"机械外推"局限 / quality 警示逐条 / cashflow 年度 OCF-FCF）——quality/cashflow 异常必须上升为风险提示
  - ⑥ 择时必含：6.1 均线系统全表（MA5~MA250 数值+现价相对位置+排列判断，MA120/250 压制要显式指出，禁笼统"多头"）→ 6.2 指标读数（MACD/KDJ/RSI6-12-24/BOLL）→ 6.3 量能与资金（量比/近10日涨跌量额/两融）→ 6.4 支撑压力（60/250日高低+斐波那契+BOLL+均线粘合位）→ 6.5 个股 vs 行业 RS 对比（差距显式）+ 缠论连续两日信号（翻转要警示）→ 6.6 近期 K 线/价格行为表 → 择时小结（关键位+两种情景路径）
  - ④⑥ 两节合计应占正文 40%+，每个结论带具体数字
