## 一、核心结论

| 指标 | B1-only | B2确认 | S级(≥80分) |
|------|---------|--------|-----------|
| 样本数 | 59,188 | 39,428 | 925 |
| 胜率 | 25.5% | 66.2% | 72.1% |
| 均收益 | -6.37% | +8.12% | +16.14% |
| 超额收益 | -5.94% | +6.58% | +13.43% |
| Kelly | 0 | 0.478 | 0.622 |

**结论1**: B1信号单独使用没有买入参考价值，胜率仅25.5%，期望收益为负。B1是"突破尝试"，不是买入信号。

**结论2**: B2确认后买入具有显著参考价值，胜率66.2%，20日平均收益8.12%，超额收益6.58%。B2才是真正的买入信号。

**结论3**: 通过5因子加权评分（RS250+回调深度+量比+横盘质量+技术分），S级信号可将胜率提升至72.1%、均收提升至16.14%，且在7/11个年度跑赢全量B2基准。

## 七、实操建议

1. **B1信号出现** → 进入观察池，不买入
2. **等待B2确认** → 触发买入评估
3. **计算5因子评分** → RS250(30) + 回调(25) + 量比(15) + 振幅(15) + 技术分(15)
4. **按分级执行**:
   - S级(≥80): 重仓，胜率72.1%
   - A级(70-79): 标准仓位
   - B级(60-69): 轻仓
   - C级(50-59): 谨慎
   - D级(<50): 不参与
5. **持有期**: 10-20个交易日最优
