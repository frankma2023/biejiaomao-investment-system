12 结论与建议

  1. 全量 MW 信号不产生超额收益。所有窗口的中位收益为负，必须通过评分筛选后才能使用。只有高分段信号优于随机选股基准。
  2. D（调整深度15%~35%）是核心预测维度。满分vs零分胜率差 +0.0pp。这是MW信号不可妥协的硬性条件。
  3. Sig（信号共振）区分力 +0.0pp。技术信号累加的边际效益需持续监控。
  4. MW信号在空头市场优于多头。空头10d胜率52.5% vs 多头36.3%，MW抓的是超跌反弹而非牛市追涨。
  5. 大市值MW信号更稳定。超大盘胜率50.6%，中盘41.1%。龙头股的二次突破更受机构关注。
  6. 实操建议：仅交易 ≥80 分的 PLUS 信号（D满分+I1满分），在空头/震荡市中优先，回避小市值、回避电气设备等行业，控制单票仓位≤2%。
