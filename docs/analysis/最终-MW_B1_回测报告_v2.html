核心认知：B1 是"突破尝试"，不是买入信号。B2 是"突破确认"。B1 日可观测的最强因子是 h_rs250（前高时的个股 RS），其次是换手率。B2 确认后买入可将胜率从 41.8% 提升至 66.2%，高收益赢家 B2 确认率高达 81.9%。

1. 背景与信号定义

1.1 MW 信号概述

MW 信号识别的是 A 股市场中"强势股在牛市中回调后再次启动"的特定形态。信号结构由五个连续的节点组成：

前高(H)  ──→  最低点(L)  ──→  横盘区(C)  ──→  B1 突破日  ──→  B2 确认日

节点含义判定条件
H（前高）股价的阶段性高点缠论笔顶，前 60 日涨幅 ≥ 20%，后续回调 ≥ 10%
L（最低点）H 之后的最低点H 之后第一个缠论笔底
C（横盘区）L 之后的窄幅整理连续振幅 < 10% 的 K 线区间，至少 3 根
B1（突破日 1）首次放量突破 C 区间涨幅 ≥ 2%，量比 ≥ 1.3，站上 MA5/MA10 且 MA5>MA10，收盘价 > C 区间最高价
B2（突破日 2）B1 之后的二次确认B1 后 30 天内，涨幅 ≥ 3%，站上 ≥ 4 条均线（含 MA60），收盘位置合格
关键区分：B1 可独立保存（B2 可能尚未发生），B2 出现后 UPDATE 已有记录。b2_date 为 NULL 表示该 B1 尚未被 B2 确认。唯一键为 (stock_code, b1_date)。

2.2 分析方法

本研究采用赢家归因法（Winner Attribution），而非预测建模。具体而言：将所有 B1 交易按是否盈利分为赢家组和输家组，对比两组在各因子上的分布差异；再将赢家组按收益大小分为高收益组（Top 25%）和中收益组，寻找高收益赢家的独有特征。此方法避免了预测模型中的过拟合风险，聚焦于可解释的因子差异。

9.2 方法论评价

GLM5.2 的数据取用和统计方法严谨正确，但存在一个关键的方法论局限：所有因子分析均在 B2 确认子集上进行。这导致评分体系只能回答"已经出了 B2 的信号里哪些更好"，无法帮助在 B1 阶段筛选哪些信号值得等待 B2。实际操作中，B1 阶段的筛选（§6.1）和 B2 后的仓位决策（§7.2）应分开处理。
