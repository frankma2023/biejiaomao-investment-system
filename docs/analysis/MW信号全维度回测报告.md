## 8. 投资决策规则

```
B1 信号出现
│
├─ B1-only 分数 < 40 → 放弃
│   （B2 确认率仅 40%，H20 净收益≈0）
│
├─ B1-only 分数 ≥ 40 → 关注
│   │
│   ├─ 次日开盘（T+1_O）买入
│   │   （T+2/T+3 延迟会侵蚀 3-7pp 胜率）
│   │
│   ├─ 等待 B2 确认
│   │   ├─ B2 出现 → 继续持有至 H20~H60
│   │   │   ├─ 高/中置信度 → 目标 H20（+17%~+22%）
│   │   │   ├─ 窗口内有 PP_V1 共现 → 加分
│   │   │   └─ 震荡市中持有信心更高
│   │   └─ B2 未出现 → H60 止损/减仓
│   │
│   ├─ 不在 B2 日追买
│   │   （B2 日买入胜率比 B1 日低 15-31pp）
│   │
│   └─ PLUS 信号 → 满仓持有
│       （胜率 91%，收益 28%，下行风险极低）
│
└─ 环境偏好：震荡市 > 牛市
    行业偏好：RS 75~85 > RS ≥85
```

## 9. 已知局限

1. **样本量不足**：高置信仅 35 条，PLUS 仅 21 条。需 2016-2022 数据补完后重新验证
2. **熊市样本极少**（59 个熊市交易日），结论不可靠
3. **B2 买入分析**样本集中在低置信区间
4. **BO_V2 共现**样本 29~66 条，结论不可靠
5. **PLUS 盈亏比 27.35** 是统计异常（亏损端几乎为零导致），实际凯利应上限截断
6. **市值和成交额**未纳入过滤条件（依赖快照表，待建）
7. **持仓期中的 MA 止损和移动止盈**未测试（属 M1 工程范围）

### 11.2 涨得差的信号特征

- 前高前涨幅过大（>70%）：之前已经暴涨过的，回调后动力不足
- B1 日涨幅过大（>8%）：涨停式追入的 B1 是坑
- 短期 RPS20 过高（>75）：短期动量股在 B1 后容易回调
- 调整过浅（<18%）：弱回调的假突破概率高
- 横盘过久（C 评分高）：越磨叽越不涨

### 11.7 底层认知

前视偏差审计未通过（真实信号 vs 随机偏移 ±5 天，差值 -1.87%，p≈0）。这意味着 MW 信号中存在「确认已发生突破」的成分大于「预测即将突破」的成分。无论怎么改信号定义，MW 在本质上是一个**趋势确认工具**，不是一个**预测工具**。

改规则能让它更精准地挑出「已经突破后继续涨的」，但不能让它变成「提前预测突破的」。这个定位认知比具体规则的修改更重要。
