七、实操建议

信号使用流程
1
B1信号出现 → 进入观察池
B1日涨幅≥2%、放量、站上MA5/MA10。不买入，仅标记观察。胜率仅25.5%，直接买入期望为负。
2
等待B2确认 → 触发买入评估
B1后30天内出现B2（涨幅≥3%、站上≥4条均线含MA60）。B2确认后胜率跃升至66.2%。
3
计算5因子评分 → 分级决策
RS250(30分) + 回调深度(25分) + 量比(15分) + 横盘振幅(15分) + 技术分(15分) = 总分。
4
按分级执行
S级(≥80) 重仓买入，胜率72.1%，均收16.14%
A级(70-79) 标准仓位，胜率69.3%，均收11.15%
B级(60-69) 轻仓试水，胜率70.2%，均收9.70%
C级(50-59) 谨慎参与，胜率68.0%，均收8.90%
D级(<50) 不参与，胜率64.4%，均收6.98%
5
持有期管理
最优持有期10-20个交易日。H10胜率最高(68.9%)，H20收益最高(8.12%)。H60胜率降至53.3%，alpha已衰减。
注意事项与局限
1. 退市股处理：daily_kline包含已退市股票，回测无 survivorship bias，但极端亏损案例已反映在VaR95中。
2. tech_score缺失：52%的B2信号tech_score=0（历史数据未计算），实际S级信号中部分可能因tech_score缺失被低估。
3. 交易成本：net_ret_pct已扣除0.3%成本（买0.125%+卖0.175%），未计滑点。
4. 样本集中：S级仅925个样本（占B2的2.3%），部分年度样本量不足（如2018年仅74个），统计显著性有限。
5. RS250的反直觉：RS250对胜率无区分度，仅放大收益。不应将RS作为唯一筛选条件。
6. 2026年数据不完整：截至7月3日，2026年仅1,185个B2信号，结论可能随全年数据变化。
