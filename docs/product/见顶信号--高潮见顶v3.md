### 2.3 高潮见顶（抛物线式上涨）
一只股票在逐渐攀升100%以上后，突然加速上涨，股价在1-2周内上涨25%-50%，从图形上看几乎是垂直上升。这种情况称为"高潮区"，是强烈的卖出信号。

#### 2.3.1 定义

**高潮见顶**（Climax Top，也称"抛物线式上涨"）是欧奈尔体系中最重要的顶部形态之一。它描述了一只股票在经历长期上涨后，突然进入**加速赶顶**阶段，股价在极短时间内（通常1-3周）以近乎垂直的角度飙升25%-50%以上，同时成交量急剧放大，形成"最后的狂欢"。这种形态标志着主力资金正在大规模派发筹码，是极其可靠的卖出信号。

#### 2.3.2 形态特征与量化规则

| 特征维度 | 量化规则 | 说明 |
|---------|----------|------|
| **前期涨幅** | 从基部突破点或口袋支点突破点算起（优先），fallback 到 20 周整理区间高点或 52 周低点，累计涨幅已超过 100% | 高潮出现在上涨行情的末期，前期已有可观涨幅 |
| **加速时间** | 1-3周内涨幅达到25%-50% | 股价上涨角度从45°陡升至80°以上 |
| **成交量** | 周成交量放大至过去20周均量的2倍以上，**或**最近3周累计量≥20周均量×5，且每日成交量均处于历史高位 | 巨量换手，机构与散户激烈博弈 |
| **K线形态** | 连续出现长阳线、跳空缺口，或带长上影线的K线 | 盘中冲高回落，显示抛压开始大于买盘 |
| **RS指标** | 短期RS（20日）达到99以上（权重8%），长期RS（250日）也处于极高水平95+（权重7%） | 极度超买，动量衰竭。RS数据不可用时不影响检测 |
| **日线加速验证** | 高潮周内最近5个交易日存在连续2天涨幅>3%且每日量>50均量×1.5 | 日线级别确认加速，额外+5%加权得分 |
| **日线提前确认** | 高潮周内若出现放量冲高回落（上影线>实体×2 + 量>50均×3）或连续2天"新高后收低"，立即提升为confirmed | 解决周线确认信号延迟问题 |
| **大盘环境** | 市场整体情绪亢奋，垃圾股、低价股开始补涨 | 牛市末期特征 |

#### 2.3.3 典型演变过程

##### 第一阶段：缓慢爬升（1-2年）
股价沿着10周或50周均线稳步上涨，每次回调幅度有限（10%-15%），成交量温和。

##### 第二阶段：加速上涨（3-6个月）
股价开始脱离均线，周线出现连续大阳线，成交量逐步放大。此时RS指标进入90以上区间。

##### 第三阶段：高潮赶顶（1-3周）
**关键特征**：
- **周线图**：出现连续2-3根长阳线，实体越来越长，上下影线很短。
- **日线图**：经常出现跳空缺口，每日涨幅3%-5%以上，盘中几乎无回调。
- **成交量**：创出上市以来天量，换手率高达10%-20%甚至更高。
- **消息面**：媒体铺天盖地宣传该股或所属板块的"重大利好"，散户蜂拥追高。

##### 第四阶段：见顶回落

在高潮周之后，股价往往出现一根带长上影线的周K线（或阴线吞噬），随后快速下跌，跌破10周均线，正式进入下降通道。

#### 2.3.4 量化识别代码框架

```python
def is_climax_top(weekly_df, daily_df=None, lookback_weeks=20):
    """
    检测周线级别的高潮见顶形态
    """
    # 1. 前期涨幅
    low_52w = weekly_df['low'].rolling(52).min().iloc[-3]  # 高潮周之前52周最低点
    prev_breakout = find_last_breakout(weekly_df)  # 最近一次基部突破点（需外部逻辑）
    gain_from_breakout = (weekly_df['close'].iloc[-3] - prev_breakout) / prev_breakout
    if gain_from_breakout < 1.0:   # 至少翻倍
        return False
    
    # 2. 高潮周检测：最近3周内是否有连续2周涨幅>15%且周成交量放大
    climax_weeks = []
    for i in range(-3, 0):
        week = weekly_df.iloc[i]
        gain = (week['close'] - weekly_df['close'].iloc[i-1]) / weekly_df['close'].iloc[i-1]
        vol_ratio = week['volume'] / weekly_df['volume'].rolling(lookback_weeks).mean().iloc[i-1]
        if gain >= 0.15 and vol_ratio >= 2.0:
            climax_weeks.append(i)
    if len(climax_weeks) < 2:
        return False
    
    # 3. 见顶确认（可选）：高潮周之后一周是否出现长上影线或阴线
    if len(weekly_df) >= 2:
        after_week = weekly_df.iloc[-1]
        climax_week = weekly_df.iloc[-2]
        # 高潮周后一周最高价无法超越高潮周最高价，且收盘价低于高潮周收盘价
        if after_week['high'] <= climax_week['high'] and after_week['close'] < climax_week['close']:
            return True
    return False
```

#### 2.3.5 交易策略建议

1. **卖出时机**：高潮周出现时不必等到见顶确认，可分批卖出。例如：
   - 高潮第一周：卖出1/3仓位
   - 高潮第二周：卖出1/3仓位
   - 若出现长上影线或周线吞噬形态：清仓剩余仓位

2. **禁止买入**：高潮见顶后至少等待股价回调50%以上且重新形成基部，才考虑重新介入。

3. **大盘联动**：若大盘也出现高潮见顶（如连续两周巨量上涨后周线反转），应整体清仓离场。

#### 2.3.6 常见误区

- **误区一**：认为"高换手率就是高潮"。实际上，部分成长股在高位维持高换手但股价继续上涨（如2020年的特斯拉），需结合涨幅速率判断。
- **误区二**：高潮后抢反弹。高潮见顶后的首次反弹往往很诱人，但大概率是"死猫跳"，风险极高。
- **误区三**：仅凭日线判断。高潮见顶必须结合周线图，避免被日内波动干扰。

---

#### 2.3.7 总结

**高潮见顶 = 前期大幅上涨（翻倍以上） + 1-3周内加速上涨25%-50% + 成交量异常放大**

这是欧奈尔体系中最强烈的卖出信号之一，一旦识别应立即采取行动，保护利润。记住：**"当最乐观的人也开始买入时，往往就是最高点。"**

|------|---------|---------|------|------|

| 见顶确认 | `climax_confirmed` | 🔴 高潮见顶确认 | strong_sell | 高潮周后出现反转蜡烛，强烈建议清仓 |

**存储**：复用现有 `portfolio_signals` 表 + `signal_engine.py` 状态机，后续新增信号规则统一接入。

### E. 评分模型设计（加权打分）

| 维度 | 权重 | 说明 |
|------|------|------|
| 前期涨幅≥100% | 25% | 从基准点到当前涨幅 |
| 1-3周加速25%-50% | 30% | 核心特征。日线加速验证通过则额外 +5% |
| 周量比≥2倍（或累计量≥5倍） | 20% | 成交量异常放大（含累计条件，见 §H） |
| K线形态（长上影/跳空/缺口） | 10% | 盘面特征 |
| RS(20日) ≥ 99 | 8% | 动量衰竭——短期 |
| RS(250日) ≥ 95 | 7% | 动量衰竭——长期 |

**满分 100% + 5%（日线加速验证加分）= 105%**。≥ 65 分触发 `climax_warning`，≥ 80 分且见顶确认触发 `climax_confirmed`。

### F. 确认信号延迟问题 —— 日线提前确认（2026-05-18 新增）

**问题**：`climax_confirmed` 需等高潮周之后一周的反转 K 线，间隔 5 个交易日。若高潮周后暴跌 15%，确认信号来晚了。

**解决**：在 `climax_warning` 触发时，**同时检查日线级别的危险信号**。若高潮周内存在以下条件，立即提升为 `climax_confirmed`：

- 某天放量冲高回落：当日上影线长度 > 实体长度 × 2，且当日量 > 50 日均量 × 3
- 或连续 2 天出现"新高后收低"：当日最高创 52 周新高但收盘低于开盘

### G. 累计量条件（2026-05-18 新增）

**问题**：连续 3 周量比分别为 1.8x、1.6x、2.1x，只有第三周触发单个 2x 条件，前两周漏了。

**解决**：周量比条件从"单周 ≥ 2x"扩展为同时接受：

- 任意一周量 ≥ 20 周均量 × 2（原有规则）
- **或**最近 3 周累计量 ≥ 20 周均量 × 5（新增累计条件）

### H. 日线加速验证（2026-05-18 新增）

**问题**：仅凭周线 K 线检查加速，可能被周内个别异常日干扰。

**解决**：加一个日线子检查。高潮周内，最近 5 个交易日内存在：

- 连续 2 天涨幅 > 3%
- 且这两天每日量 > 50 日均量 × 1.5

通过日线加速验证的 `climax_warning` 信号，**额外 +5% 加权得分**（加在"1-3 周加速"维度上）。
