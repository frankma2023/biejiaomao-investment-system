# 缠论每日精选 — 产品需求书

> 版本：v1.0 | 日期：2026-06-01 | 状态：✅ 已完成  
> API：`/api/chanlun-daily-selection`  
> 页面路径：`web/discipline/chanlun-daily.html`  

---

## 1. 产品概述

### 1.1 定位

观察池 + 缠论信号 = 双重认证。每天自动扫描最新观察池中当日有缠论买入信号的股票，按综合分排序展示。

### 1.2 解决的问题

观察池页面展示的是 RS 动量筛选后的股票列表，但不知道哪些股票在当前结构位置上有缠论买入信号。本页面补齐这一环：**一眼看到两套体系在同一天同时点头的股票**。

### 1.3 三级漏斗

```
最新观察池 ~450只
    │
    ▼ 当日缠论买入信号 ~280只
    │
    ▼ 交集精选（本页展示）
```

## 2. 数据来源

### 2.1 数据管道

```
discipline_observation_pool  ──┐
                                ├── /api/chanlun-daily-selection ──→ 页面
chanlun_scan_daily          ──┘
```

| 数据表 | 字段 | 用途 |
|------|------|------|
| `discipline_observation_pool` | stock_code, stock_name, rs_category, rps_20, rps_250, cansim_total, composite_score | 观察池基础信息 |
| `chanlun_scan_daily` | latest_trade_type, latest_trade_side, latest_trade_price, bi_count, zs_count | 缠论信号 |

### 2.2 API 端点

```
GET /api/chanlun-daily-selection?date=2026-06-01
```

返回：

```json
{
  "date": "2026-06-01",
  "pool_count": 463,
  "scan_count": 286,
  "count": 286,
  "items": [{
    "stock_code": "600519",
    "stock_name": "贵州茅台",
    "industry_name": "食品饮料",
    "rs_category": "龙头",
    "rps_20": 88, "rps_250": 92,
    "canslim_total": 45,
    "composite_score": 72.0,
    "trade_type": "三买",
    "trade_price": 1680.50,
    "bi_count": 85, "zs_count": 3,
    "latest_bi_dir": "向上",
    "latest_bi_power": 12.5
  }]
}
```

### 2.3 筛选逻辑

SQL 关联条件：
- `discipline_observation_pool.date = chanlun_scan_daily.scan_date`（同日）
- `latest_trade_side = 'buy'`（仅买入信号）
- 按 `composite_score DESC` 排序

## 4. 设计决策

| 决策 | 结论 | 理由 |
|------|------|------|
| 数据来源 | 关联查询而非实时分析 | 450+ 只实时缠论分析太慢，`chanlun_scan_daily` 已是现成缓存 |
| 信号类型 | 一买/二买/三买/类一买 | 四类全覆盖，不遗漏 |
| 排序基准 | 观察池综合分 | 综合分反映 RS+基本面+信号，排序合理 |
| 跳转目标 | 缠论分析页面 | 点击代码直接看 K 线图和详细信号 |

---

## 5. 每日更新依赖

`daily_update.py` 执行顺序：

1. **步骤 14**：观察池日更 → 写入 `discipline_observation_pool`
2. **步骤 17**：缠论批量扫描 → 写入 `chanlun_scan_daily`
3. 页面自动读取最新数据

> 如果步骤 14 或 17 失败，本页面将显示前一日的缓存数据。

## 6. 与回测对比的关系

| 页面 | 看的维度 | 时间锚定 |
|------|---------|---------|
| 缠论每日精选 | 今天谁有信号 | 最新一天 |
| 缠论vs欧奈尔回测 | 历史上信号赚不赚钱 | 可选日期 + 远期收益验证 |

每日精选是"发现"，回测对比是"验证"。两者互补。
