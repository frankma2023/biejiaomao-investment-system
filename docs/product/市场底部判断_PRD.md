# 市场底部判断 · PRD

状态：v1.0（2026-11-17）
作者：投研系统
位置：`docs/product/市场底部判断_PRD.md`
关联页面：`web/market-scan/index.html`

---

## 一、背景

用户问「现在是不是底部区域」。当前系统有「大盘健康分」与「大盘卖出评分」，两者衡量的是**当下强弱**（顺势指标），不回答**位置**问题。健康分 34 分只说明现在很弱，不说明离底还有多远。

把这次人工分析的判据固化成每日计算的量化功能，放进大盘扫描页，供每天收盘后一眼看到「位置」。

## 二、目标

1. 给出**综合判定**：底部区域 / 接近底部 / 未到底部，并附一句话依据。
2. 下方按判据拆成卡片，每张卡显示实测值、阈值、是否满足、得分。
3. 覆盖三个指数：沪深300（000300）、创业板指（399006）、科创50（000688）。**不能用沪深300 代表全市场** —— 2026-11-17 同一天，沪深300 跌 21.4%、创业板跌 47.6%、科创50 跌 44.7%，位置完全不同。
4. 每天随 `scripts/daily_update.py` 自动计算入库，页面只读。

## 三、非目标

- 不预测点位、不给买卖建议。判定只描述「位置」，不描述「该买多少」。
- 不判断个股底部。
- 不做盘中实时计算，只用收盘数据。

## 四、判据与阈值

阈值全部来自 2008-2026 年七次历史底部的实测区间（见附录 A）。按 100 分制给分：**指数层主判据每项 8 分（半分 4），细分判据每项 4 分（半分 2）；全市场层主判据每项 7 分（半分 3.5），量能子项分别为 4 分与 3 分。**

### 4.1 分指数判据（每个指数 4 项）

| # | 判据 | 满分 | 半分 | 0 分 |
|---|---|---|---|---|
| I1 | 自本轮周期高点回撤 | 8：沪深300 ≥30%，创业板/科创50 ≥50% | 4：沪深300 20~30%，创业板/科创50 40~50% | 低于半分线 |
| I2 | 下跌历时（交易日） | 8：≥150 | 4：100~150 | <100 |
| I3a | 估值分位（PE 或 PB 任一） | 4：≤10% | 2：≤20% | >20% |
| I3b | 股债差 ERP 的历史分位 | 4：≥90% | 2：≥80% | <80% |

**单个指数得分 = 四项直接相加，满分 24 分**（例：沪深300 回撤 4 + 历时 4 + 估值 2 + 股债差 0 = 10 / 24）。

I3b 用**分位**而不是绝对值，因为 ERP 的绝对水平跨指数不可比（创业板 E/P 天生高，ERP 2.2pp 已是 95% 分位；沪深300 5.8pp 才 80% 分位）。页面上仍显示绝对值，方便与「股债差 6% 是历史大底」这类常见说法对照。

「本轮周期高点」定义：近 **750** 个交易日内收盘最高值（约 3 年，覆盖一轮牛熊）。不用「历史最高点」——沪深300 价格指数从未超过 2007 年 5,891 点，用历史最高点会把 2016 年之后每一次下跌都算成「距 2007 年泡沫的回撤」。

**为什么是 750，不是 250**：拿七个历史底部做标定（沪深300，格式「复算 / 附录 A 实测」），W=250 时 2022-10-31 只算出 31%（实际 40%）、2024-02-02 只 24%（实际 45%）、2024-09-13 只 17%（实际 46%），三次全被低估，阈值等于被悄悄收紧；W=750 时五个完全命中、两处偏差 ≤8pp 且方向为低估；W=1000 起 2019-01-03 反而偏大，W=1500 会把当前回撤算成 31.5%（虚高）。

| 回看窗 | 2008 | 2016 | 2019 | 2020 | 2022 | 2024-02 | 2024-09 |
|---|---|---|---|---|---|---|---|
| 250 日 | 72/72 | 47/47 | 32/32 | 16/16 | **31/40** | **24/45** | **17/46** |
| 500 日 | 40/40 | — | — | — | **34/45** | **25/46** | — |
| **750 日** | **72/72** | **47/47** | **32/32** | 20/16 | **40/40** | **45/45** | 38/46 |
| 1000 日 | — | — | **45/32** | — | — | — | 46/46 |

### 4.2 全市场判据（5 项）

| # | 判据 | 满分 | 半分 | 0 分 |
|---|---|---|---|---|
| M1a | 缩量比（全市场成交额 ÷ 前 250 日均值） | 4：≤0.70 | 2：≤0.90 | >0.90 |
| M1b | 量能转向（5 日均 ≥20 日均 ×1.05 且连续 3 日放量） | 3：两项都满足 | 1.5：满足其一 | 都不满足 |
| M2 | 破净率（PB<1 个股占比） | 7：≥12% | 3.5：≥10% | <10% |
| M3 | 杠杆出清（**融资余额**较近 750 日高点回落） | 7：≥15% 且近 5 日不再创新低 | 3.5：两者之一 | 都不满足 |
| M4 | 右侧确认（三项同时） | 7：健康分≥50 且卖出分≤60 且收盘站上 MA60 | 3.5：满足两项 | 满足≤1 项 |

全市场五项直接相加，满分 28 分。

M1 拆成两段，是因为「先缩量、再温和放量」是两个不同的时点：缩量说明抛压衰竭，放量说明有人承接。只测缩量会在反弹初期把信号拿掉，只测放量会在下跌中段误报。

**缺数据的判据不进分母**。融资余额、健康分、卖出分都只从 2026-01-05 起有数，历史日期这三项算不出来；股债差在 2016 年之前无 10Y 序列。旧版一律记 0 分，等于给历史底部罚分（2019-01-03 只有 66.7 分）。现在只对有值的判据求和，并在 `meta.missing` 里列明缺了哪几项。

### 4.3 综合判定

**满分构成：三个指数各 24 分（合计 72）+ 全市场 28 分 = 100 分。各判据直接相加，不做二次加权。**

综合分 = 实得 ÷ 可用满分 × 100（缺数据的判据从分母里去掉，历史日期因此是 x/86 或 x/62）。页面同时显示原始分与比例，例如「40.5 / 100 分（40.5%）」。

指数层占 72%、全市场层占 28%，与「位置定权重、全市场做确认」的取舍一致 —— 等权时 2022-10-31 这种指数层拿满 72 分、全市场层 0 分的真实底部会被压低。

| 综合分（比例） | 判定 |
|---|---|
| ≥65% | 底部区域 |
| 45% ~ 65% | 接近底部 |
| <45% | 未到底部 |

判定给三个字 + 一句依据（例：「未到底部 · 沪深300 仅回撤 21.4%，PE 分位 68%，估值未到位；创业板已到 4% 分位」）。

## 五、统计口径

| 项目 | 定义 |
|---|---|
| 价格序列 | `index_daily_kline` 的 `close`（`kline_type='normal'`），不复权指数点位 |
| 回撤 | (本轮周期高点 − 当日收盘) ÷ 本轮周期高点 |
| 本轮周期高点 | 近 750 个交易日收盘最大值，及其日期 |
| 下跌历时 | 高点日之后至当日的交易日数 |
| PE / PB 分位 | 该指数自身 `index_fundamental_daily` 全历史（2016-01 起，科创50 自 2020-07 起）升序分位 |
| 缩量比 | 当日全市场成交额 ÷ 此前 250 个交易日成交额均值；成交额来自派生表 `mv_market_amount` |
| 破净率 | 当日 `fundamental_indicator` 中 `metric_code='pb'` 且 `value<1` 的个股数 ÷ 有 PB 的个股数 |
| 融资余额 | `daily_margin_history` 按日汇总 `financing_balance`，单位亿元。**口径只含融资、不含融券**：融券余额约 224 亿元，占两融合计 1.1%，融券以机构对冲为主，散户几乎不参与；判断杠杆力度用融资口径足够，页面与文案也不再称「两融」（2026-11-19 订正）。**不用 `daily_review_margin`**：后者是理杏仁 `mtasl` 接口的当日抓取快照，交易所 T+1 才公布余额，其 `date` 实际装的是前一交易日数据（个股逐日核对 `review[D] == history[D-1]`，全样本 207 天平均绝对差 713 亿元），且 2026-05~07 有未刷新的冻结段。数据日与行情日不同步，`meta.margin_date` 记录实际数据日 |
| 健康分 / 卖出分 | `market_health_daily.total_score` / `market_sell_score_daily.total_score` |
| 股债差（ERP） | 100 ÷ PE − 10 年国债收益率；`bond_yield_daily.y10` 与指数 PE 按日对齐，取该指数自身历史分位 |
| 量能转向 | 成交额 5 日均值 ≥ 20 日均值 ×1.05，且最近 3 个交易日逐日高于各自 20 日均值 |
| MA60 | `index_daily_kline` 沪深300 收盘 60 日均值 |

## 六、产物

### 6.1 数据表

```sql
CREATE TABLE IF NOT EXISTS market_bottom_daily (
  date        TEXT PRIMARY KEY,
  verdict     TEXT,      -- 底部区域 / 接近底部 / 未到底部
  score       REAL,      -- 0~100
  summary     TEXT,      -- 一句话依据
  payload     TEXT,      -- JSON：indices[] + market[] + meta
  updated_at  TEXT
);
```

`payload` 结构：

```json
{
  "indices": [{"code","name","close","peak","peak_date","dd","days",
               "pe","pe_pct","pb","pb_pct","dyr","score","items":[{key,label,value,threshold,score}]}],
  "market":  [{"key","label","value","threshold","score","detail"}],
  "meta":    {"data_date","amount_ratio","break_net","margin","margin_peak",
              "margin_dd","health","sell","ma60"}
}
```

### 6.2 计算入口

- 模块：`src/scanners/market_bottom.py`，`compute(conn, date) -> dict`、`save(conn, date, d)`、`main()`。
- 脚本：`scripts/compute_market_bottom.py --date YYYY-MM-DD`（默认最近交易日）。
- 日更：`scripts/daily_update.py` 第 43 步。

### 6.3 API

`GET /api/market-bottom?date=YYYY-MM-DD`（缺省最近一个交易日）
返回：`{status, date, verdict, score, summary, indices, market, meta}`
无数据返回 `{status:'no_data', date}`。

### 6.4 页面

位置：大盘扫描页顶部，日期条下方、「主要指数」上方。
结构：
1. 总结果条：判定文字（按判定着色）+ 原始分（如「40.5 / 100 分（40.5%）」）+ 一句话依据。
2. 卡片区：
   - 三张指数卡（沪深300 / 创业板指 / 科创50），卡题写「沪深300 · 10/24」，卡内显示回撤、历时、PE 分位、PB 分位、ERP 与四项小分（8 / 8 / 4 / 4）。
   - 五张全市场卡（缩量、量能转向、破净、杠杆、右侧确认），满分依次 4 / 3 / 7 / 7 / 7。
3. 每张卡右上角显示「满足 / 部分 / 不满足」标签（按得分率 100% / ≥50% / <50% 三档）。

## 七、验收标准

1. `python scripts/compute_market_bottom.py` 能算出当日结果并入库，重复运行幂等。
2. 2026-11-18 的判定为「未到底部」，得分 40.5 / 100（40.5%），创业板卡显示回撤 47.1%、PE 分位 4%、得分 12/24。
3. 页面 `/market-scan/` 顶部出现该区块，五张市场卡与三张指数卡数值与接口一致。
4. 接口缺数据时页面显示「暂无数据」，不报错、不白屏。
5. 历史底部回测自检：2024-09-13 → 83/86（96%）、2024-02-02 → 79/86（92%）、2019-01-03 → 59/62（95%）、2016-01-28 → 44/62（71%）、2022-10-31 → 63/86（73%），五个历史底部全部判「底部区域」。

## 八、风险与已知缺陷

1. **PE 分位会被盈利周期扭曲**。科创50 当前 PE 88.5 仍在 63% 分位，因为成分盈利下滑比股价快。故 I3 用「PE 或 PB 任一达标」，PB 更能反映资产端定价。
2. **2016 年前无指数估值数据**，2008 与 2014 两次底部只能验证价格与成交量维度，不能验证估值维度。
3. **融资余额数据仅自 2026-01 起**，M3 在早期日期无法回溯。
4. **破净率与缩量比是全市场口径**，不能按指数拆分。
5. 判定是位置描述，与经济基本面无关。业绩底可能晚于估值底 1~2 个季度。
