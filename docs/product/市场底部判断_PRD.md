# 市场底部判断 · PRD

状态：v1.0（2026-11-17）
作者：投研系统
位置：`docs/product/市场底部判断_PRD.md`
关联页面：`web/market-scan/index.html`

---

## 一、背景

用户问「现在是不是底部区域」。当前系统有「大盘健康分」与「大盘卖出评分」，两者衡量的是**当下强弱**（顺势指标），不回答**位置**问题。健康分 34 分只说明现在很弱，不说明离底还有多远。

把这次人工分析的判据固化成每日计算的量化功能，放进大盘扫描页，供每天收盘后一眼看到「位置」。

## 二、目标

1. 给出**综合判定**：底部区域 / 接近底部 / 未到底部，并附一句话依据。
2. 下方按判据拆成卡片，每张卡显示实测值、阈值、是否满足、得分。
3. 覆盖三个指数：沪深300（000300）、创业板指（399006）、科创50（000688）。**不能用沪深300 代表全市场** —— 2026-11-17 同一天，沪深300 跌 21.4%、创业板跌 47.6%、科创50 跌 44.7%，位置完全不同。
4. 每天随 `scripts/daily_update.py` 自动计算入库，页面只读。

## 三、非目标

- 不预测点位、不给买卖建议。判定只描述「位置」，不描述「该买多少」。
- 不判断个股底部。
- 不做盘中实时计算，只用收盘数据。

## 四、判据与阈值

阈值全部来自 2008-2026 年七次历史底部的实测区间（见附录 A）。每条判据得分 0 / 0.5 / 1。

### 4.1 分指数判据（每个指数 3 条）

| # | 判据 | 满分(1) | 半分(0.5) | 0 分 |
|---|---|---|---|---|
| I1 | 自本轮周期高点回撤 | 沪深300 ≥30%，创业板/科创50 ≥50% | 沪深300 20~30%，创业板/科创50 40~50% | 低于半分线 |
| I2 | 下跌历时（交易日） | ≥150 | 100~150 | <100 |
| I3 | 估值分位（PE 或 PB 任一） | ≤10% | ≤20% | >20% |

单指数得分 = (I1 + I2 + I3) / 3。

「本轮周期高点」定义：近 **750** 个交易日内收盘最高值（约 3 年，覆盖一轮牛熊）。不用「历史最高点」——沪深300 价格指数从未超过 2007 年 5,891 点，用历史最高点会把 2016 年之后每一次下跌都算成「距 2007 年泡沫的回撤」。

**为什么是 750，不是 250**：拿七个历史底部做标定（沪深300，格式「复算 / 附录 A 实测」），W=250 时 2022-10-31 只算出 31%（实际 40%）、2024-02-02 只 24%（实际 45%）、2024-09-13 只 17%（实际 46%），三次全被低估，阈值等于被悄悄收紧；W=750 时五个完全命中、两处偏差 ≤8pp 且方向为低估；W=1000 起 2019-01-03 反而偏大，W=1500 会把当前回撤算成 31.5%（虚高）。

| 回看窗 | 2008 | 2016 | 2019 | 2020 | 2022 | 2024-02 | 2024-09 |
|---|---|---|---|---|---|---|---|
| 250 日 | 72/72 | 47/47 | 32/32 | 16/16 | **31/40** | **24/45** | **17/46** |
| 500 日 | 40/40 | — | — | — | **34/45** | **25/46** | — |
| **750 日** | **72/72** | **47/47** | **32/32** | 20/16 | **40/40** | **45/45** | 38/46 |
| 1000 日 | — | — | **45/32** | — | — | — | 46/46 |

### 4.2 全市场判据（4 条）

| # | 判据 | 满分(1) | 半分(0.5) | 0 分 |
|---|---|---|---|---|
| M1 | 缩量比（全市场成交额 ÷ 前 250 日均值） | ≤0.70 | ≤0.90 | >0.90 |
| M2 | 破净率（PB<1 个股占比） | ≥12% | ≥10% | <10% |
| M3 | 杠杆出清（两融余额较近 750 日高点回落） | ≥15% 且近 5 日不再创新低 | ≥15% 或 5 日止跌之一 | 都不满足 |
| M4 | 右侧确认（三项同时） | 健康分≥50 且卖出分≤60 且收盘站上 MA60 | 满足两项 | 满足≤1 项 |

**缺数据的判据不进分母**。两融、健康分、卖出分都只从 2026-01-05 起有数，历史日期这四项算不出来；旧版一律记 0 分，等于给历史底部罚分（2019-01-03 只有 66.7 分）。现在按 `_avg()` 只对有值的判据取均值，并在 `meta.missing` 里列明缺了哪几项。

### 4.3 综合判定

综合分 = 三个指数得分均值 × **0.7** + 全市场得分均值 × **0.3**，换算为 0~100。

指数层给 0.7 是因为「位置」主要由价格跌幅与估值决定；全市场层（缩量、破净、杠杆、右侧）是确认信号，不该与位置等权 —— 等权时 2022-10-31 这种指数层 83 分、全市场层 25 分的真实底部只有 54 分。

| 综合分 | 判定 |
|---|---|
| ≥65 | 底部区域 |
| 45 ~ 65 | 接近底部 |
| <45 | 未到底部 |

判定给三个字 + 一句依据（例：「未到底部 · 沪深300 仅回撤 21.4%，PE 分位 68%，估值未到位；创业板已到 4% 分位」）。

## 五、统计口径

| 项目 | 定义 |
|---|---|
| 价格序列 | `index_daily_kline` 的 `close`（`kline_type='normal'`），不复权指数点位 |
| 回撤 | (本轮周期高点 − 当日收盘) ÷ 本轮周期高点 |
| 本轮周期高点 | 近 750 个交易日收盘最大值，及其日期 |
| 下跌历时 | 高点日之后至当日的交易日数 |
| PE / PB 分位 | 该指数自身 `index_fundamental_daily` 全历史（2016-01 起，科创50 自 2020-07 起）升序分位 |
| 缩量比 | 当日全市场成交额 ÷ 此前 250 个交易日成交额均值；成交额来自派生表 `mv_market_amount` |
| 破净率 | 当日 `fundamental_indicator` 中 `metric_code='pb'` 且 `value<1` 的个股数 ÷ 有 PB 的个股数 |
| 两融 | `daily_review_margin` 按日汇总 `fb_balance`，单位亿元 |
| 健康分 / 卖出分 | `market_health_daily.total_score` / `market_sell_score_daily.total_score` |
| MA60 | `index_daily_kline` 沪深300 收盘 60 日均值 |

## 六、产物

### 6.1 数据表

```sql
CREATE TABLE IF NOT EXISTS market_bottom_daily (
  date        TEXT PRIMARY KEY,
  verdict     TEXT,      -- 底部区域 / 接近底部 / 未到底部
  score       REAL,      -- 0~100
  summary     TEXT,      -- 一句话依据
  payload     TEXT,      -- JSON：indices[] + market[] + meta
  updated_at  TEXT
);
```

`payload` 结构：

```json
{
  "indices": [{"code","name","close","peak","peak_date","dd","days",
               "pe","pe_pct","pb","pb_pct","dyr","score","items":[{key,label,value,threshold,score}]}],
  "market":  [{"key","label","value","threshold","score","detail"}],
  "meta":    {"data_date","amount_ratio","break_net","margin","margin_peak",
              "margin_dd","health","sell","ma60"}
}
```

### 6.2 计算入口

- 模块：`src/scanners/market_bottom.py`，`compute(conn, date) -> dict`、`save(conn, date, d)`、`main()`。
- 脚本：`scripts/compute_market_bottom.py --date YYYY-MM-DD`（默认最近交易日）。
- 日更：`scripts/daily_update.py` 第 43 步。

### 6.3 API

`GET /api/market-bottom?date=YYYY-MM-DD`（缺省最近一个交易日）
返回：`{status, date, verdict, score, summary, indices, market, meta}`
无数据返回 `{status:'no_data', date}`。

### 6.4 页面

位置：大盘扫描页顶部，日期条下方、「主要指数」上方。
结构：
1. 总结果条：判定文字（按判定着色）+ 综合分 + 一句话依据。
2. 卡片区：
   - 三张指数卡（沪深300 / 创业板指 / 科创50），每张显示回撤、历时、PE 分位、PB 分位与单项得分条。
   - 四张全市场卡（缩量、破净、杠杆、右侧确认）。
3. 每张卡右上角显示「满足 / 部分 / 不满足」标签。

## 七、验收标准

1. `python scripts/compute_market_bottom.py` 能算出当日结果并入库，重复运行幂等。
2. 2026-11-17 的判定为「未到底部」，综合分 42.2，创业板卡显示回撤 47.6%、PE 分位 4%。
3. 页面 `/market-scan/` 顶部出现该区块，四张市场卡与三张指数卡数值与接口一致。
4. 接口缺数据时页面显示「暂无数据」，不报错、不白屏。
5. 历史底部回测自检：把计算日期设为 2019-01-03、2024-02-02，判定应为「底部区域」—— 实测 100 分与 85 分，通过；2022-10-31 得 58 分（接近底部），原因是当日缩量比 0.91、破净率 9.7% 都不达标，属可解释偏差。

## 八、风险与已知缺陷

1. **PE 分位会被盈利周期扭曲**。科创50 当前 PE 88.5 仍在 63% 分位，因为成分盈利下滑比股价快。故 I3 用「PE 或 PB 任一达标」，PB 更能反映资产端定价。
2. **2016 年前无指数估值数据**，2008 与 2014 两次底部只能验证价格与成交量维度，不能验证估值维度。
3. **两融数据仅自 2026-01 起**，M3 在早期日期无法回溯。
4. **破净率与缩量比是全市场口径**，不能按指数拆分。
5. 判定是位置描述，与经济基本面无关。业绩底可能晚于估值底 1~2 个季度。
