## 1. 产品概述

### 1.1 定位

观察池是整个投资系统的**股票初筛层**。从全市场约 5300 只 A 股中，按动量（RS）、基本面（CANSLIM）、信号（形态扫描）三维度综合评分，**综合分 ≥ 45 分**的股票进入观察池。

### 1.2 与后续环节的关系

```
全市场 ~5300只
    │
    ▼ 硬性门槛（正常上市 + RPS数据 + 流动性 ≥ 5000万）
~2000只
    │
    ▼ RS分类 + 综合评分 ≥ 45
~200~400只  ← 观察池（视市场阶段波动）
    │
    ▼ 精选池 / 每日扫描 / 缠论分析 / 回测对比
```

## 2. 入选条件

### 2.1 硬性门槛（全部必须满足）

| 条件 | 规则 | 数据源 |
|------|------|------|
| 上市状态 | `listing_status = 'normally_listed'` | `stock_basic` |
| RS 数据 | `rps_250 IS NOT NULL` | `stock_rs_daily` |
| 流动性 | 日均成交额 ≥ 5000 万 | `stock_rs_daily.amount` |

### 2.2 RS 动量分类（满足硬性门槛后，至少匹配一类）

| 分类 | 条件 | 标签色 |
|------|------|:--:|
| 🟣 龙头 | RPS250 ≥ 90 且 RPS20 ≥ 85 | 紫色 |
| 🔵 加速 | RPS250 ≥ 80 且 RPS20 ≥ 95 | 青色 |
| 🟢 稳健 | RPS250 ≥ 85 且不满足龙头 | 绿色 |
| 🔴 短爆 | RPS20 ≥ 95 且不满足加速 | 蓝色 |
| 🔥 双强 | 同时满足龙头+加速 | 红色 |

分类采用排他性优先级：龙头 → 加速 → 短爆 → 稳健。

### 2.3 综合评分门槛（核心筛选）

```
综合分 ≥ 45 分  ← 最终准入条件
```

## 3. 综合评分公式

### 3.1 公式

```
综合分 = 0.2 × RPS250 + 0.2 × RPS20 + 0.3 × CANSLIM + 信号分
```

四项均在 0~100 尺度上。

### 3.2 信号分规则

信号满分 30 分。对过去 10 天内出现的买入信号，按类型和时间衰减累加：

**信号类型与单次贡献值**：

| 信号 | 贡献值 | 计算方式 | 来源引擎 |
|------|:--:|------|------|
| 基部突破 | 9 分 | 30% × 30 | `base_breakout.py` |
| 口袋支点 | 9 分 | 30% × 30 | `pocket_pivot.py` |
| TA-Lib 看涨 | 4.5 分 | 15% × 30 | `talib` |
| K线看涨 | 3 分 | 10% × 30 | `cdl` |

**时间衰减**：

| 信号距离目标日 | 系数 |
|:--:|:--:|
| 0~3 天 | × 1.0 |
| 4~6 天 | × 0.7 |
| 7~10 天 | × 0.4 |

**计分规则**：
- 同类型信号多次出现，每次都计分（不合并）
- 不同类型信号分别计分后累加
- 上限 30 分，超出截断
- 无信号或仅有负面信号（突破失败/顶部形态/抛盘日）→ 0 分

### 3.3 计算示例

**例1：3天内出现1次基部突破**
```
RPS250=92  RPS20=88  CANSLIM=45
信号分 = 9 × 1.0 = 9

综合分 = 0.2×92 + 0.2×88 + 0.3×45 + 9
       = 18.4 + 17.6 + 13.5 + 9
       = 58.5  → 入选 ✅（≥ 45）
```

**例2：无信号，CANSLIM偏低**
```
RPS250=80  RPS20=75  CANSLIM=25  信号分=0

综合分 = 0.2×80 + 0.2×75 + 0.3×25 + 0
       = 16 + 15 + 7.5
       = 38.5  → 不入选（< 45）
```

**例2：5天前1次基部突破 + 2天前1次口袋支点 + 3天前1次K线看涨**
```
RPS250=95  RPS20=92  CANSLIM=55

信号分 = 9×0.7(基部5天前) + 9×1.0(口袋2天前) + 3×1.0(K线3天前)
       = 6.3 + 9 + 3
       = 18.3

综合分 = 0.2×95 + 0.2×92 + 0.3×55 + 18.3
       = 19 + 18.4 + 16.5 + 18.3
       = 72.2  → 入选 ✅
```

**例3：3天内出现2次基部突破 + 1次TA-Lib看涨 + 1次K线看涨**
```
RPS250=90  RPS20=85  CANSLIM=60

信号分 = 9×1.0 + 9×1.0 + 4.5×1.0 + 3×1.0
       = 25.5 (未触及30上限)

综合分 = 0.2×90 + 0.2×85 + 0.3×60 + 25.5
       = 18 + 17 + 18 + 25.5
       = 78.5  → 入选 ✅
```

## 7. 设计决策记录

| 决策 | 结论 | 理由 |
|------|------|------|
| 综合分阈值 | ≥ 45 | CANSLIM 实际分布 0~78（均值~25），RPS 0~100（均值~50），加权后 45 分约对应前 30~50% 的股票，保留观察价值 |
| 信号时间衰减 | 3/6/10天三档 | 近期信号更有参考价值 |
| 同信号多次计分 | 每次都计 | 多次突破信号累积效应有意义 |
| CANSLIM 不入池门槛 | 仅计入评分 | 需跨日期可比，阈值过滤已间接控制质量 |
| CANSLIM 分数分布 | 实际 0~78，均值 ~25 | 并非所有维度都能得满分，25 分即中等偏上水平 |
