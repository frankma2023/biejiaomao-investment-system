## 1. 页面定位

大盘扫描页面（`web/market-scan/index.html`）是用户每日查看市场状态的第一入口。v2.3 在原有全市场健康分基础上，新增**行业分组健康分卡片**，帮助用户在结构性分化的市场中识别强势板块与弱势板块。

### 1.1 解决的问题

- 全市场健康分只有一个数字（如53分C级），无法反映科技/AI板块暴涨 vs 消费板块暴跌的极端分化
- 用户需要知道："我可以买吗？如果能买，该买哪个方向？"
- 行业分组健康分将同一个评分体系应用到不同行业的股票子集上，给出板块级别的答案

### 2.2 行业分组卡片规格

三大指数池 × 三档强/中/弱 = **9 张卡片**：

| 池 | 来源 | 数量 | 说明 |
|------|------|:---:|------|
| L2 | `sector_l2` | 45 | 中证二级行业指数 |
| 主题 | `thematic` | 229 | L3 行业主题指数 |
| 策略 | `strategy` | 93 | 绩优/ESG/红利等策略指数 |

每组按 RS_20 分三档：≥75 强势、30~74 中性、<30 弱势。

每张卡片包含：

```
┌────────────────────┐

│ ────────────────   │

│ 建议仓位 65%       │ ← 仓位建议
│ ↑ 强于大盘 +29     │ ← 与全市场对比（仅强势/弱势组显示）
└────────────────────┘
```

**配色规则：**

| 评级 | 卡片底色 | 数字颜色 |
|------|---------|---------|
| A/B | 绿色调（rgba(16,185,129,0.08)） | `--rise` |

### 2.3 行业分组算法

分组基于 L2 行业指数和主题指数的 **RS_20**（近 20 个交易日的截面相对强度百分位）：

| 分组 | RS_20 阈值 | 含义 |
|------|:---:|------|
| 强势组 | ≥ 75 | 近 20 日跑赢 75% 以上的指数 |
| 中性组 | 30~74 | 中间区域 |
| 弱势组 | < 30 | 近 20 日跑输 70% 以上的指数 |

**v2.4 变更（2026-07-30）**：将 RS_60 改为 RS_20。RS_60 反映过于迟钝（60 日均值），在快速轮动市场中无法及时反映板块强弱变化。RS_20 更灵敏，能捕捉到近期资金流向。

> 分组计算在 `market_health.py` 的 `_get_sector_index_rs()` 中完成。L2 和主题分别独立分组，各产生强/中/弱三组，共 6 组。

### 2.4 当日行业分组快照（新增 v2.6）

在「行业分组健康分」区块**下方**新增独立区块「📊 行业分组健康分 · 当日」，与 RS_20 分组并排显示，用于识别趋势与当日行情的分化（如 20日RS强势组当日大跌）。

**与 RS_20 分组的定位差异**：RS_20 分组是趋势口径（决策评级，含总分/评级/仓位），当日分组是快照口径（仅描述当日强弱，不含评级）。

#### 2.4.1 分组算法（当日涨跌幅百分位）

- **指标**：当日涨跌幅——`index_daily_kline.change` 仅 1% 粒度，实际用 `close/前一交易日close−1` 反推精确值（prev 缺失时降级 change）
- **排名**：L2 / 策略 / 主题 **三个池子各自独立**做百分位排名，得到当日强度分 0-100
- **分组阈值**（与 RS_20 一致）：

| 分组 | 当日强度分阈值 | 含义 |
|------|:---:|------|
| 强势组 | ≥ 75 | 当日涨幅跑赢同池 75% 以上指数 |
| 中性组 | 30~74 | 中间区域 |
| 弱势组 | < 30 | 当日涨幅跑输同池 70% 以上指数 |

**与 RS_20 分组的对比**：RS_20 基于 `index_rs_daily.rs_20`（20日截面百分位），当日分组基于当日涨跌幅的单日截面百分位，两者口径独立、互不影响。

#### 2.4.2 卡片内容（快照 + 技术面概览）

每组卡片包含：

```
┌────────────────────────┐
│ L2强势·当日            │ ← 组名（池+档位+当日标识）
│ +1.23%                 │ ← 组内当日平均涨跌幅（红涨绿跌）
│ 6指数 · MA50↑4/6 · RS_20均63.1 │ ← 指数数 + 技术面概览
│ ────────────────────   │
│ 5涨1跌                 │ ← 组内涨跌家数
└────────────────────────┘
```

- **技术面概览（v2.8 新增）**：与 RS_20 分组卡片同口径，显示 MA50 上方指数数/总数 + 组内 RS_20 均值——用于**当日分组 vs 20日趋势对照**（识别单日异动 vs 趋势共振）
- **不显示**：总分、评级、建议仓位（避免与 RS_20 卡片的评级/仓位冲突）
- **排序**：强势/中性/弱势三段固定顺序，组内按当日平均涨跌幅降序

#### 2.4.3 展示规则

- 新区块标题：`📊 行业分组健康分 · 当日`

### 2.5 大盘操作建议 · 红利指数规则引擎（新增 v2.7）

基于 2016-2026 全周期回测验证的规律，将红利指数买卖规则引擎化，每日自动检测并给出操作建议。回测结论：**买入信号有效**（250日回撤≥15% → 20日胜率 65.8%）、**卖出信号无效**（跌破均线/高PE等与随机基准无差异），故模块以买入信号为主、估值警示为辅。

#### 2.5.1 监控范围

默认 5 个核心红利指数（预留扩展）：

| 指数 | 代码 | 类别 |
|------|------|------|
| 中证红利 | 000922 | 纯红利 |
| 红利低波 | H30269 | 红利低波 |
| 红利质量 | 931468 | 红利质量/成长 |
| 红利指数 | 000015 | 纯红利 |
| 800红利低波 | 931848 | 红利低波 |

#### 2.5.2 三层规则结构

**第一层：信号检测（客观事实）**

| 信号 | 条件 | 回测依据 |
|------|------|---------|
| gold_buy（黄金买点） | 250日回撤 ≥ 15% | 胜率 65.8%，平均 +2.53% |
| high_div（高息买点） | 股息率分位 > 90% | 胜率 61.5% |
| double_confirm（双确认买点） | 回撤 ≥ 15% 且 股息率分位 > 80% | 双重信号共振 |
| pe_warn（估值警示） | PE 分位 > 80% | 非卖出信号，作估值警示 |
| low_div（低息警示） | 股息率分位 < 10% | 股息保护不足警示 |

**第二层：建议合成**

| 触发组合 | 建议 | 等级 |
|---------|------|------|
| double_confirm | 分批买入（回撤+高息双确认） | strong_buy |
| gold_buy 或 high_div | 观察买入（单信号触发） | buy |
| pe_warn 且 回撤<10% | 估值偏高（PE分位>80%），建议减仓 | reduce |
| low_div | 股息保护不足，谨慎 | caution |
| 其他 | 持有/观望 | hold |

**第三层：仓位** — 不输出，用户自行安排。

#### 2.5.3 页面展示

- 区块标题：`📌 大盘操作建议`（副标题标注"红利指数规则引擎 · 回测验证"）
- 顶部一行整体汇总（如"3/5 指数处于买入区，红利整体低估"）
- 每个指数一张卡片（复用 `.sector-card` 样式）：
  - 建议等级（强买入/买入/减仓/谨慎/观望）按等级配色
  - 建议文案（如"分批买入（回撤+高息双确认）"）
  - 250日回撤幅度（≥15% 红色、≥10% 琥珀、其他灰）
  - PE分位 / 股息率分位

- 点击卡片 → 独立详情页 `dividend-advice-detail.html?code=CODE&date=DATE`

#### 2.5.4 详情页（dividend-advice-detail.html）

ECharts 四块图表 + 统计 + 建议：

1. **历史回撤曲线**（近3年，标注 15% 买点虚线 + 历史买点 markPoint）
2. **估值分位走势**（PE/PB/股息率分位三线，近3年）
3. **价格走势 + 买点信号时间线**（markPoint 标注历史触发点）
4. **历史类似情况统计**（当前回撤幅度下，全历史所有类似事件）：
   - 统计数字行：类似次数、20/60日收益中位、20/60日胜率、反弹幅度中位、到峰值天数中位
   - 明细表：触发日期/回撤/20日收益/60日收益/反弹幅度/到峰天数

#### 2.5.5 API

**GET `/api/market-scan/dividend-advice?date=YYYY-MM-DD`**（date 缺省=最新交易日）
返回：`{date, summary, indices: [{code, name, cat, close, dd_250, high_250, valuation{pe,pe_pct,pb,pb_pct,dyr,dyr_pct}, signals[], advice, advice_level}]}`

**GET `/api/market-scan/dividend-advice-detail?code=000922&date=YYYY-MM-DD`**
返回：`{code, name, date, dates[], closes[], dd_series[], pe_series[], pb_series[], dyr_series[], events[], similar[], stats{count, fwd20_median, fwd20_winrate, fwd60_median, fwd60_winrate, bounce_median, bounce_avg, days_to_peak_median}, current_dd}`

**计算口径**：
- 250日回撤 = (250日滚动最高收盘 - 当前收盘) / 250日滚动最高
- 估值分位直接读 `index_fundamental_daily` 的 `pe_ttm_pct` / `pb_pct` / `dyr_pct`
- 历史类似事件用**全历史数据**（2016起，20日去重），避免目标日期截断的幸存者偏差
- 买入价口径：信号确认后次日（验收时以收盘价为参考）

#### 2.5.6 验收机制（三层）

1. **历史回看**：API 支持 `?date=` 任意历史日期，可核对已知节点：
   - 2026-03-12（红利高点）→ 应输出 3/5 指数"估值偏高减仓"
   - 2026-06-30（集体见底）→ 应输出 3/5 指数"买入区"
   - 2026-07-31（反弹后）→ 买点信号消失
2. **命中率自检**：详情页历史类似事件统计（如中证红利 6/30 时 23 次、胜率 69.6%）与全周期回测 65.8% 同量级
3. **日常监控**：API 任意日期回看即可持续追踪

## 4. 交互设计

### 4.1 默认行为

页面加载时显示最新日期的数据（当天 or 最近交易日）。

### 4.2 日期切换

顶部日期选择器支持切换历史日期，查看历史行业分组健康分。切换时所有卡片同步更新。

### 4.3 点击交互

- 点击行业分组卡片 → 打开独立页面 `/market-scan/sector-detail.html?group=GROUP_NAME&date=DATE`，展示该组的指数列表、RS/MA 数据、成分股钻取。顶部 6 个 Tab 切换强/中/弱 × L2/主题。
- 点击放量突破数 → 跳转至独立页面 `/market-scan/breakouts.html`，展示放量突破个股明细表格（含筛选排序、点击股票代码跳转 pattern-scan）
- 鼠标悬停在分数上 → tooltip 显示7指标的详细得分

### 4.4 放量突破明细页面（v2.3 新增）

独立页面 `web/market-scan/breakouts.html`，从辅助指标卡片中「放量突破数」点击进入。

**页面结构**：
- 顶部：标题「🚀 放量突破个股」+ 日期标签
- 筛选栏：代码/名称搜索、突破均线筛选（MA200~MA5）、涨跌方向筛选
- 排序：点击列头升序/降序，支持量比、均线级别排序
- 表格列：

| 列 | 字段 | 说明 |
|----|------|------|
| 代码 | `stock_code` | 衬线字体，金色，点击新标签打开 `../pattern-scan/?code=xxxxxx` |
| 名称 | `name` | 来自 `stock_basic` |
| 涨跌幅 | `change_pct` | 红涨绿跌，百分比格式 |
| 成交金额 | `amount` | 金额格式化（亿/万） |
| MA50均量 | `vol_ma50` | 金额格式化 |
| 成交量倍数 | `vol_ratio` | `volume / vol_ma50`，如 `2.5x` |
| 突破均线 | `break_ma` | 标签样式，MA200/MA120 红色强调，其他琥珀色 |

**接口**：`GET /api/market-health/breakouts?date=latest`，返回：

```json
{
  "date": "2026-07-13",
  "count": 110,
  "stocks": [{
    "stock_code": "601162",
    "name": "天风证券",
    "change_pct": 0.0242,
    "amount": 1535690738,
    "vol_ma50": 208634962,
    "vol_ratio": 1.93,
    "break_ma": "MA120"
  }]
}
```

**计算规则**（`compute_vol_breakout`）：
- 突破均线：`close > MA5/10/20/50/120/200`，取被突破的最高级别（MA200 优先于 MA120 优先于 MA50...）
- 成交量倍数：`volume / MA50(volume)`，已经过滤 ≥ 1.5 的才入库

**数据库**：`market_breakout_daily` 表扩展 `vol_ratio REAL`、`break_ma TEXT` 两列。

### 4.5 资金情绪卡片交互

- 三列卡片默认显示汇总数字，两融卡片含迷你趋势图
- 点击任一卡片展开详情（手风琴模式，同时只有一个展开项）
- 独立页面margin.html：个股融资余额+融券余额+净买入三图
- 龙虎榜展开：净买入Top10 + 净卖出Top10 两个表格
- 大宗交易展开：全部明细（含占流通市值比例）

### 4.6 数据更新

页面每60秒自动刷新（仅当天日期时）。非当天日期不自动刷新。

## 6. 非功能需求

- 页面加载时间 < 2秒（API + 渲染），行业分组数据在API中已计算好，前端不做计算
- 行业分组卡片适配移动端单列布局
- 与现有全市场健康分卡片保持视觉一致性（同色系、同字体、同间距）
- **当日分组快照为实时计算，前端与 API 层 <10ms 开销，不引入额外数据库表与日更任务（v2.6）**
