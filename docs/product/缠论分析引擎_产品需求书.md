## 一、产品概述

### 1.1 定位

缠论分析引擎是蹩脚猫投资系统的**择时层**核心。它不负责选股（那是欧奈尔 CAN SLIM 的职责），而是对任意股票回答三个问题：

1. 当前处于什么走势结构？（看懂）
2. 是否有可操作的买卖信号？（发现）
3. 历史信号质量如何？当前信号可信吗？（验证）

### 1.2 与欧奈尔体系的分工

```
欧奈尔 CAN SLIM              缠论引擎
─────────────────            ─────────────────
选股 (What)                   择时 (When)
量化评分 + 排序                结构定性 + 信号匹配
池子基本面过滤                  买卖点分级
机械执行                      人工判断辅助

协作方式：欧奈尔出池 → 缠论判结构 → 结构允许才操作
```

### 1.3 技术栈

- 语言：Python 3.12
- 核心依赖：CZSC（缠中说禅计算库）
- K线数据：SQLite (lixinger.db) + Baostock 分钟数据
- API 服务：Flask（8788端口）
- 前端：原生 JS + ECharts 5.5 + hanako-glass 设计系统（8772端口）

## 三、形态学层

### 3.1 分型检测

依赖 CZSC 库的 `fx_list`，识别顶分型和底分型。分型是笔的起点和终点。

**输出字段**：`dt`, `fx_type`, `high`, `low`

### 3.2 笔计算

由 CZSC 库自动完成，相邻分型之间的连接构成笔。笔方向严格交替（上→下→上→下）。

每笔包含：起止时间（`sdt`/`edt`）、方向（`direction`）、高低点（`high`/`low`）、力度（`power`）、斜率（`slope`）、角度（`angle`）。

### 3.3 线段计算

`compute_segments(bi_list_raw)` — 从笔合成线段。至少3笔有重叠才能构成线段。输出包含起止时间、方向、笔数、高低区间、振幅。

`compute_segment_zs(segment_list)` — 在线段上构建中枢（线段级别中枢）。

### 3.4 中枢检测

`compute_zhongshu(bi_list_raw)` — 滑动窗口检测每3笔的重叠区间。

**判定规则**：取三笔的高点最小值（ZG）和低点最大值（ZD），若 ZG > ZD 则形成中枢。

**合并逻辑**：相邻且重叠超过50%的中枢自动合并为一个延伸中枢，避免重复计数。

**输出字段**：`start_dt`, `end_dt`, `zg`, `zd`, `zz`(中轴), `width`, `width_pct`, `bi_indices`, `bi_count`

### 3.5 K线周期合成

`_synthesize_klines(df, target_freq)` — 从日线合成周线/月线 OHLC。

支持 `W`（周线）和 `M`（月线），输出包含 `period_date`, `open`, `high`, `low`, `close`, `volume`, `amount`。

### 3.6 未完成笔

分析结果中包含 `ubi`（Unfinished BI）字段，反映当前正在形成但尚未确认的笔。用于获取最新的实时方向和价格。

## 四、动力学层

### 4.1 背驰检测

`detect_divergence(bi_list_raw, zs_list)` — 检测两类背驰。

#### 趋势背驰

中枢前后两段同向趋势的力度衰减。算法：
- 遍历所有笔，比较 `bi[i]` 和 `bi[i+2]`（间隔一个反向笔）
- 若同向且力度比 `< 0.6`，判定为背驰
- 向下笔力度衰减 → 底背驰
- 向上笔力度衰减 → 顶背驰

**严重程度分级**：力度比 `< 0.3` 为"强"，`< 0.45` 为"中"，否则"弱"。

#### 盘整背驰

中枢内部震荡的力度衰减。算法：
- 对每个中枢，比较进入中枢的第一笔和离开中枢的最后一笔
- 若同向且力度衰减 `< 0.6`，判定为盘整背驰

**输出字段**：`type`, `category`, `dt`, `bi_idx`, `power_ratio`, `prev_power`, `curr_power`, `severity`

## 五、信号体系层

### 5.1 信号总览

`generate_trade_signals(bi_list_raw, zs_list, divergence_signals)` — 统一的信号生成函数。

| 信号 | 方向 | 触发条件 | 置信度逻辑 |
|:--:|:--:|------|------|
| 一买 | 买 | 趋势底背驰 | 强→高，中→中，弱→低 |
| 一卖 | 卖 | 趋势顶背驰 | 同上 |
| 二买 | 买 | 一买后反弹再回调，回调低点 > 一买低点 | 高 |
| 二卖 | 卖 | 一卖后下跌再反弹，反弹高点 < 一卖高点 | 高 |
| 三买 | 买 | 向上离开中枢后回调不破 ZG | 高 |
| 三卖 | 卖 | 向下离开中枢后反弹不破 ZD | 高 |
| 类一买 | 买 | 盘整底背驰（中枢内向下衰竭） | 强→中，中→低 |
| 类一卖 | 卖 | 盘整顶背驰（中枢内向上衰竭） | 同上 |

### 5.2 一买/一卖

来自趋势背驰信号。一买在向下笔的低点，一卖在向上笔的高点。判断条件：`div["category"] == "趋势背驰"`。

### 5.3 二买/二卖

**二买**：一买信号后 → 第1笔向上反弹 → 第2笔向下回调 → 回调低点高于一买低点 → 确认反转。

**二卖**：一卖信号后 → 第1笔向下 → 第2笔向上反弹 → 反弹高点低于一卖高点 → 确认反转。

实现方式：一买/一卖生成时附加 `bi_idx`，后续遍历所有一买/一卖信号，检查后续两笔是否满足条件。

### 5.4 三买/三卖

基于中枢位置判断：
- **三买**：中枢最后一笔之后，先向上离开（`out_bi`），再向下回调（`ret_bi`），回调低点 > ZG
- **三卖**：先向下离开，再向上反弹，反弹高点 < ZD

### 5.5 类一买/类一卖

来自盘整背驰信号。判断条件：`div["category"] == "盘整背驰"`。

类买卖点的置信度比标准买卖点低一档：盘整背驰发生在中枢震荡中，突破方向不确定。

## 六、结构定性层

### 6.1 走势类型判断

`classify_trend(zs_list, bi_list, ubi)` — 判断当前走势属于上涨趋势、下跌趋势还是盘整。

**第一步：中枢关系分析**

| 走势类型 | 判定规则 | 最小中枢数 |
|---------|---------|:--:|
| 上涨趋势 | 所有相邻中枢 ZG[i] < ZD[i+1]（无重叠，依次上移） | 2 |
| 下跌趋势 | 所有相邻中枢 ZD[i] > ZG[i+1]（无重叠，依次下移） | 2 |
| 盘整 | 只有一个中枢，或有中枢重叠 | 0 |

**第二步：当前价格修正**

优先使用未完成笔 `ubi` 的实时价格。若当前价格已离开最新中枢：
- 价格 < ZD + 向下笔 → 追加"正在向下离开盘整区"描述
- 价格 > ZG + 向上笔 → 追加"正在向上离开盘整区"描述
- 上涨趋势但价格跌破 ZD → 追加"趋势可能转弱"警告
- 下跌趋势但价格突破 ZG → 追加"趋势可能转强"警告

**输出字段**：`trend_type`, `direction`, `zs_count`, `description`, `confidence`, `position_vs_zs`, `latest_range`

### 6.2 使用场景

结构定性是买入决策的**第一道门**：
- 上涨趋势 → 🟢 允许买入
- 盘整偏多（盘整+方向向上+价格在上方） → 🟡 允许（等突破确认）
- 盘整/盘整偏空/下跌趋势 → 🔴 不买

## 七、背驰后追踪层

### 7.1 功能

`track_divergence_outcomes(divergence_signals, bi_list, zs_list)` — 对每条历史背驰信号，追踪后续实际走势结果。

### 7.2 三种结果

| 结果 | 含义 | 判定规则 |
|------|------|---------|
| 反趋势（最强） | 背驰有效，走势真正反转 | 后续形成新中枢且完全在原中枢上方（底背驰）或下方（顶背驰） |
| 更大级别盘整（较弱） | 反转了一点但继续磨 | 后续形成新中枢但与原中枢有重叠 |
| 中枢扩展（最弱） | 背驰失败 | 未形成新中枢，原中枢震荡延续 |

### 7.3 辅助函数

`_detect_zs_in_bis(bi_list)` — 在指定笔段内检测中枢（简化版，不做延伸合并）。

### 7.4 使用场景

背驰后追踪是买入决策的**第三道门**——历史校验：
- 统计某股票历史上"反趋势"的占比
- 占比 ≥ 30% 才允许通过信号过滤器
- 占比越高，同类信号的可信度越高

## 八、决策层

### 8.1 三步规则链

`evaluate_buy_decision(code)` — 对单只股票输出买入决策。三步串行，任一不过即终止。

```
Step 1: 结构过滤
  上涨趋势？ → 通过
  盘整偏多（方向向上+价格在ZG上方）？ → 通过
  其他 → 否决，理由："结构不满足"

Step 2: 信号匹配
  有买入信号？ → 取最优信号类型
  信号分级：三买(3) > 二买(2) > 类一买(1) > 一买(1)
  无信号 → "观察"，理由："结构允许但无买入信号"

Step 3: 历史校验
  背驰后追踪中"反趋势"占比 ≥ 30%？ → 通过
  否则 → 否决
```

**输出**：`decision`（买入/观察/不买）, `grade`（⭐⭐⭐/⭐⭐/⭐/—）, `reason`（完整理由链）

### 8.2 回测用过滤器

`filter_signals_by_rules(analyze_result)` — 与 `evaluate_buy_decision` 同逻辑，但接收 `analyze()` 的输出结果（不重复调用），用于批量回测时的高效过滤。

### 8.3 历史质量评分

`_evaluate_signal_quality(outcomes)` — 根据背驰后追踪计算 0-100 分：反趋势=100分，更大级别盘整=50分，中枢扩展=0分，加权平均。

## 九、多周期分析

### 9.1 日/周/月三周期联立

`multi_period_analyze(code)` — 对同一股票同时分析日线、周线、月线。

每个周期独立跑完整的形态学+动力学+信号流程。

### 9.2 共振分析

`_analyze_resonance(results)` — 分析三周期之间的协调关系：

| 共振类型 | 判定 | 贡献分 |
|---------|------|:--:|
| 笔方向一致 | 三周期最后一笔方向相同 | 2 |
| 中枢重叠 | 两个周期的中枢有价格重叠 → 大级别中枢确认 | 2 |
| 背驰共振 | 两个以上周期同月出现背驰 | 每项2 |
| 买卖点共振 | 两个以上周期同月出现买卖点 | 每项3 |

共振强度：≥6分为"强"，≥3分为"中"，否则"弱"。

## 十、区间套分析

### 10.1 三级级联

`cascade_analyze(code)` — 日线→60分钟→15分钟三级级联，精确定位入场时机。

### 10.2 数据源

分钟K线来自 Baostock，表 `stock_kline_15min` / `stock_kline_60min`。

### 10.3 级联逻辑

1. 在日线级别找到买卖点
2. 在对应日期的60分钟线确认背驰
3. 在60分钟背驰当日，到15分钟线找精确入场点

输出：置信度（通过级数/3级）、级联信号列表（含每日级别的背驰详情）、精确入场价和入场区间。

## 十二、回测体系

### 12.1 缠论 vs 欧奈尔回测对比

`src/scanners/chanlun_backtest_compare.py`

**功能**：
- 对观察池股票回溯3个月的缠论买入信号表现
- 三组对比：
  - A组：缠论信号 vs 同股随机买入（5/10/20日持有）
  - B组：高/中/低置信度信号分别统计
  - C组：按信号类型（一买/三买/二买/类一买）统计
- 历史存档到 `history/` 目录，前端可按日期切换

**规则链模式**（`--filter` 参数）：
- 启用后对每只股票应用三步规则链
- 只有结构允许 + 信号匹配 + 历史质量达标的信号才计入统计
- 同步输出 `data.json`（过滤后）和 `data_raw.json`（未过滤），便于对比过滤效果

**运行命令**：
```bash
python src/scanners/chanlun_backtest_compare.py --filter --obs-date 2026-04-01
```

## 十六、设计原则

1. **画线不改**：分型、笔、中枢的 CZSC 算法保持稳定，不因上层需求调整底层形态学
2. **信号不发**：背驰判定的数学逻辑（力度比 < 0.6）不因结构位置改变
3. **过滤在后**：结构定性层和决策层在信号发出之后做过滤，而非修改信号生成逻辑
4. **数据驱动**：回测结果（过滤前后的收益率差异）是判断过滤器是否有效的唯一标准
5. **规则透明**：每一步过滤都有明确的 reason 字段，可追溯可质疑

1. **级别递归未实现**：当前使用固定K线周期（日/周/月）而非缠论标准的递归级别（1F→5F→30F→日线）。对股票操作来说日线级别通常足够，但理论严格性有欠缺
2. **中枢新生/扩张关系**：`compute_zhongshu()` 只做了简单的重叠合并，中枢之间的扩张、新生（9段升级）未实现
3. **盘整背驰的类买卖点评级**：当前置信度简单降一档，未根据中枢规模和离开力度做更精细的判断
4. **回测数据量有限**：观察池历史仅约8天快照，样本量不足以做统计显著的回测结论
5. **一买左侧属性**：一买本质是左侧交易（在下跌趋势中买），规则链将其降为1星只是权宜之计，实际应与结构位置联动（周线下跌末端的一买可能比日线盘整的三买更有价值）
