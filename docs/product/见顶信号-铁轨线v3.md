### 2.2 铁轨线（Railroad Tracks）

#### 2.2.1 形态定义

##### 2.2.1.1 三种形态类型

铁轨线在实际应用中存在三种主流定义，它们可以同时并存：

| 类型 | 周期 | 构成 | 信号级别 | 说明 |
|------|------|------|----------|------|
| **欧奈尔原著（周线卖出）** | 周线 | 连续两根周K线 | 🔴 S级·强力卖出 | 牛市终结卖出信号。第一周巨幅波动，第二周价格停滞、涨幅极小 |
| **经典双根形态** | 日线 | 两根相邻日K线 | 🟡 A级·反转预警 | 两根K线的上下影线都很长，实体极短，形似铁轨 |
| **单根强化变体** | 日线 | 一根日K线 | ⚪ B级·变盘提示 | 单根长腿十字星，上下影线都极长，实体近乎为零 |

**优先级**：欧奈尔周线版（S级）> 日线双根（A级）> 日线单根（B级）。日线版作为反转预警信号，需后续K线确认，不建议独立作为买卖依据。

**与现有规则的关系**：
- 日线铁轨线可与抛盘日、量价背离等规则联动，生成综合"反转风险评分"
- 周线铁轨线与高潮见顶可能同时触发，两者从不同角度描述顶部，取更激进的建议

---

#### 2.2.1.2 欧奈尔原著定义（周线卖出信号）

铁轨线是欧奈尔在周线图上发现的一种顶部反转形态，得名于其K线组合形状类似于铁轨的横截面。它通常出现在股票经历大幅上涨后的高位，是机构大规模出货的典型特征，预示趋势可能逆转。

**形态特征**：连续两周的周K线，第一周出现巨大的价格波动（通常是大阳线或长上下影线），第二周价格波动幅度非常小（十字星、小阴线或小阳线），且第二周的收盘价未能超越第一周的高点，成交量往往巨大。

#### 2.2.2 量化规则

##### 2.2.2.1 时间限定
- **连续两周**：指严格紧挨着的两个交易周，即周K线编号 N 和 N+1，中间不能跳过任何周。
- 使用自然周（周一至周五）或交易日周均可，但必须连续。

##### 2.2.2.2 位置限定（必须出现在大幅上涨之后）
- 需计算从最近一个明确的基部突破点（或从过去12个月的低点）到当前形态开始前的累计涨幅。
- **“大幅上涨”的量化标准**：
  - 标准：累计涨幅 ≥ 50%（相对基部突破点或过去12个月低点）。
  - 强化标准（高胜率）：累计涨幅 ≥ 100%。
- 若涨幅不足，该形态的可信度较低，可视为普通整理。

##### 2.2.2.3 形态细节

###### 第一周（Week 1）
- **价格波动幅度大**：周振幅（(最高-最低)/最低）≥ 15%（可配置）。
- 可以是阳线（收盘>开盘）或阴线，但通常是大阳线或长上影线。
- 成交量明显放大（可选，但加分项）。

###### 第二周（Week 2）
- **实体非常小**：周实体（|收盘-开盘|） ≤ 周振幅的 30%，且实体绝对值 ≤ 过去10周平均实体的 50%。
- **涨幅小**：周涨幅（(收盘-前周收盘)/前周收盘） ≤ 2%（可以是负值，即下跌）。
- **未能突破第一周高点**：第二周的最高价 ≤ 第一周的最高价（严格条件）或 ≤ 第一周最高价的 101%（宽松条件）。
- 允许第二周是**阴线**（下跌），这比小阳线更具反转意义。

###### 成交量特征（辅助确认）
- 第一周和第二周的成交量均处于近期高位（如高于过去20周均量的1.5倍）。
- 第二周虽然价格波动小，但成交量依然巨大，表明机构在高位持续派发。

#### 2.2.3 代码实现伪代码

```python
def is_railroad_tracks(weekly_df, lookback_weeks=20, min_gain=0.5, 
                       week1_amp_threshold=0.15, week2_entity_ratio=0.3,
                       week2_max_gain=0.02, strict_high=True):
    """
    检测周线铁轨线形态
    
    Parameters:
    -----------
    weekly_df : pd.DataFrame
        周线数据，必须包含 'open','high','low','close','volume'
    lookback_weeks : int
        计算涨幅的回溯周数（默认20周）
    min_gain : float
        大幅上涨的最小涨幅（50%）
    week1_amp_threshold : float
        第一周最小振幅（15%）
    week2_entity_ratio : float
        第二周实体占振幅的最大比例（30%）
    week2_max_gain : float
        第二周最大涨幅（2%）
    strict_high : bool
        是否严格要求第二周最高价 <= 第一周最高价
    """
    if len(weekly_df) < lookback_weeks + 2:
        return False
    
    # 取最近两周
    week1 = weekly_df.iloc[-2]
    week2 = weekly_df.iloc[-1]
    
    # 1. 大幅上涨检查
    # 方式一：从最近20周低点到本周开始前
    low_20w = weekly_df['low'].iloc[-lookback_weeks-1:-2].min()
    gain_from_low = (week1['close'] - low_20w) / low_20w
    if gain_from_low < min_gain:
        return False
    
    # 方式二：也可从最近基部突破点计算（需额外传入）
    
    # 2. 第一周大幅波动
    week1_amp = (week1['high'] - week1['low']) / week1['low']
    if week1_amp < week1_amp_threshold:
        return False
    
    # 3. 第二周小实体
    week2_amp = (week2['high'] - week2['low']) / week2['low']
    week2_entity = abs(week2['close'] - week2['open']) / week2['low']
    if week2_amp > 0:   # 防止除零
        entity_ratio = week2_entity / week2_amp
    else:
        entity_ratio = 1
    if entity_ratio > week2_entity_ratio:
        return False
    
    # 4. 第二周涨幅小
    week2_gain = (week2['close'] - week1['close']) / week1['close']
    if abs(week2_gain) > week2_max_gain:
        return False
    
    # 5. 未能突破第一周高点
    if strict_high:
        if week2['high'] > week1['high']:
            return False
    else:
        if week2['high'] > week1['high'] * 1.01:
            return False
    
    # 6. 可选：成交量验证
    avg_vol = weekly_df['volume'].rolling(20).mean().iloc[-3]  # 前20周均量
    if week1['volume'] < avg_vol * 1.5 or week2['volume'] < avg_vol * 1.2:
        # 不强制，但可降低置信度
        pass
    
    return True
```

#### 2.2.4 常见变体与注意事项

1. **第二周为阴线**：比小阳线更可靠，可直接卖出。
2. **第二周为十字星**：开盘价与收盘价几乎相等，实体极小，是经典铁轨线。
3. **成交量**：若第二周缩量，可能是短期整理而非见顶，需结合其他信号判断。
4. **周线 vs 日线**：铁轨线定义在周线上，日线中类似形态称为“孕线”或“十字星”，意义不同。


#### 2.2.5 常见疑问

##### 信号分级

单级信号 + 置信度评分

理由：
- 铁轨线是**两周K线对比即可确定的形态**，不存在“需要后续确认”的演进过程（不像高潮见顶需要观察加速周后的反转）
- 形态本身就代表“机构已在高位完成派发”，是直接卖出信号，不需要 warning/confirmed 两级
- 成交量条件作为**辅助确认**，用于区分“典型铁轨线”和“疑似铁轨线”


##### 第二周跌幅大的情况

建议：-2% ≤ 第二周涨幅 ≤ 2%

理由：
- 铁轨线的**核心语义**是“第一周巨量冲高，第二周完全无力上涨（停滞）”，反映的是买盘枯竭，而不是卖盘涌出
- 第二周大跌（如-5%）应该被**其他卖出规则捕获**：
  - 若跌破关键均线 → 七周规则 / 跌破50日线
  - 若放量下跌 → 抛盘日 / 量价背离
  - 若持续下跌 → 连续下跌信号
- 保持铁轨线的**形态纯粹性**，避免与其它规则重叠造成重复计数

欧奈尔说“周涨幅 ≤ 2%（可以是负值，即下跌）”，但未明确“跌幅不限”。为避免歧义，建议明确为：
```text
第二周涨幅 = (week2_close - week1_close) / week1_close
条件：-2% ≤ 第二周涨幅 ≤ 2%
```
即允许小幅下跌（≤2%），但不包含大跌（>2%跌幅）。


##### 持久化策略

铁轨线信号触发后有效8周，8周后降级为历史记录。

| 阶段 | 行为 |
|------|------|
| 触发后0-8周 | 活跃信号，在K线图上标记，持续提醒 |
| 8周后 | 移至历史记录表，不再主动提醒 |
| 清除条件 | 股价从触发周收盘价回落 ≥20% 时，标记为“已执行”或“已失效” |

**原因**：
- 8周足以让形态的影响显现（若真是顶部，8周内股价应有明显下跌）
- 若8周后股价未跌反而创新高，说明形态可能是“假信号”，不再提醒合理
- 回落20%可作为“已确认顶部”的清除条件（与高潮见顶一致）

**状态机设计**：
```python
# 铁轨线信号状态
PENDING = 'pending'       # 刚触发，活跃提醒
EXPIRED = 'expired'       # 超过8周，不再活跃
CONFIRMED = 'confirmed'   # 股价回落≥20%，确认顶部
INVALIDATED = 'invalid'   # 8周后股价未跌反而创新高（可选）
```

##### 与现有规则的关系

独立触发、独立显示。

铁轨线和高潮见顶可能同时触发（例如一只股票在高潮周的第二周恰好形成铁轨线），两者从不同角度描述顶部：

| 形态 | 关注点 | 时间框架 |
|------|--------|----------|
| 高潮见顶 | 加速上涨的动能衰竭 | 1-3周加速 + 反转确认 |
| 铁轨线 | 两周K线的具体形态对比 | 固定的两周窗口 |

**实现方案**：
- 两个信号独立检测、独立存储
- 看板上分别展示两张卡片（或合并展示，但注明同时触发）
- 仓位决策：取**更激进**的建议（如高潮见顶建议清仓，铁轨线建议减仓，则取清仓）


##### 成交量条件的定位

核心条件必须全过，但成交量影响置信度，不强制。

**核心条件（必须全满足）**：
1. **位置限定**：前期累计涨幅 ≥ 50%
2. **第一周**：周振幅 ≥ 15%
3. **第二周**：实体 ≤ 周振幅 × 30%
4. **第二周**：-2% ≤ 周涨幅 ≤ 2%
5. **价格关系**：第二周最高价 ≤ 第一周最高价（或 ≤ 第一周最高价 × 1.01）

**成交量条件（辅助，不强制）**：
- 第一周成交量 > 过去20周均量 × 1.5
- 第二周成交量 > 过去20周均量 × 1.2

**置信度规则**：
- 满足0个成交量条件 → `confidence = 'low'`
- 满足1个成交量条件 → `confidence = 'medium'`
- 满足2个成交量条件 → `confidence = 'high'`



#### 2.2.6 总结

| 维度 | 量化条件 |
|------|----------|
| **时间** | 连续两周，不可间断 |
| **位置** | 出现在累计涨幅 ≥ 50% 之后 |
| **第一周** | 周振幅 ≥ 15% |
| **第二周** | 实体占比 ≤ 30%，严格 -2% ≤ 第二周涨幅 ≤ 2%，大跌归其他规则 |
| **价格关系** | 第二周最高价 ≤ 第一周最高价 |
| **成交量** | 两周均处于近期高位，辅助，影响置信度，不强制 |
| **与高潮见顶关系** | 独立触发、独立显示，取更激进建议 |
| **持久化** | 8周有效期，回落≥20%清除 |
| **信号分级** | 单级 `strong_sell` + 置信度评分 |

该形态出现后，建议立即减仓或清仓，尤其是当大盘也出现抛盘日累积时。

#### 2.2.7 日线铁轨线（通用版）—— A/B 级反转预警

日线级别的铁轨线包括两种子类型：**经典双根形态（A级）**和**单根强化变体（B级）**。它们都是反转预警信号，需后续K线确认。

##### 2.2.7.1 经典双根形态（A级）

| 条件 | 量化规则 |
|------|---------|
| 构成 | 两根相邻日K线，中间不可间隔 |
| 位置 | 出现在上升趋势末端（收盘价 > MA50 且 距52周高点 < 10%） |
| 实体 | 两根K线的实体均 ≤ 当日振幅的 20%（即影线占比 ≥ 80%） |
| 影线 | 每根K线都需要同时具备长上影线和长下影线——上影线 ≥ 振幅×0.35 **且** 下影线 ≥ 振幅×0.35 |
| 阴阳 | 不强制一阴一阳，但若为"一阳一阴"则升级为 A+ 级 |
| 成交量 | 两根K线的成交量均 > 前5日均量（辅助，不强制） |
| 确认 | 第三根K线（形态之后的那根）收盘 < 形态低点，则确认反转有效 |

##### 2.2.7.2 单根强化变体（B级）

| 条件 | 量化规则 |
|------|---------|
| 构成 | 单根日K线 |
| 位置 | 出现在上升趋势末端（收盘价 > MA50 且 距52周高点 < 10%） |
| 实体 | 实体 ≤ 当日振幅的 15%（即影线占比 ≥ 85%） |
| 影线 | 上影线 ≥ 振幅×0.4 **且** 下影线 ≥ 振幅×0.4（比双根更严格） |
| 成交量 | 当日成交量 > 前5日均量 × 1.2 |
| 确认 | 后一根K线收盘 < 当日低点，则升级为"反转确认" |

##### 2.2.7.3 日线铁轨线的局限性

日线铁轨线（无论双根还是单根）**不建议独立作为买卖信号**。原因：

- 日线级别噪音大，类似形态在震荡市频繁出现
- 缺乏欧奈尔周线版的"前期大幅上涨"上下文，假信号率高
- 应与其他规则（抛盘日计数、量价背离、RS强度）联动使用

**建议用途**：
- 在个股看板上作为"反转预警"标记
- 与成交量、RS指标联动，生成综合"反转风险评分"
- 当同时出现周线铁轨线 + 日线铁轨线时，确认度最高

##### 2.2.7.4 A/B 级信号分级

| 信号 | 级别 | 标签 | 行为 |
|------|------|------|------|
| 日线双根（一阳一阴） | A+ | 🟠 铁轨预警+ | 强反转预警，关注后续K线 |
| 日线双根（同向或任意） | A | 🟡 铁轨预警 | 反转预警 |
| 日线单根长腿十字星 | B | ⚪ 长腿十字星 | 变盘提示，需确认 |
| 日线+后续K线确认 | 升级 | 原级别→确认 | 确认反转有效 |
