> 版本：v3.0 | 日期：2026-07-07 | 状态：✅ B1/B2 信号流重设计
> 代码名：Cockpit（驾驶舱）
> 前端页面：`http://localhost:8772/cockpit/`
> 数据源：`GET /api/mw/signals`（复用现有 API）
> 参考：`MW信号识别引擎_产品需求书.md` `MW信号赢家因子分析报告.md` `MW_B2_回测报告.html`

## 1. 产品概述

### 1.1 解决的问题

用户拥有 MW 信号引擎，每天产出数十个 B1 信号和若干 B2 确认信号。但 B1 信号整体胜率仅 41.8%，需要从中筛选出最值得关注的高质量 B1；B2 确认后胜率升至 66.2%，但不同形态质量的 B2 收益差异巨大（MW 评分 ≥70 时 78% vs <50 时 63%）。

驾驶舱的职责：**用 B1 关注度评分筛选值得等的 B1，用 MW 形态评分决定 B2 的仓位。**

### 1.2 设计哲学

不搞复杂的多因子管道。两个评分体系、两个 Tab、一条流程：

```
B1 关注度 ≥80 → 加入观察池 → 等待 B2 确认 → B2 出现 → 按 MW 评分定仓位
```

### 1.3 用户角色

唯一用户：个人独立投资者。每天打开驾驶舱，B1 Tab 看有哪些值得盯的突破尝试，B2 Tab 看有哪些已确认的买入机会及对应仓位。

## 2. 系统架构

### 2.1 数据流

```
mw_signal_daily（每日扫描最新日期）
        │
        ▼
  GET /api/mw/signals?type=b1&start={date}&end={date}
  GET /api/mw/signals?type=b2&start={date}&end={date}
        │
        ▼
  前端筛选 + 排序 + 渲染
```

**不依赖后端管道、不依赖预计算。** 直接复用现有的 MW 信号 API，前端做筛选和渲染。

### 2.2 组件清单

| 组件 | 路径 | 职责 |
|------|------|------|
| 前端页面 | `web/cockpit/index.html` | 驾驶舱主页面，纯前端 |
| 后端 API | `/api/mw/signals`（已有） | 按日期 + 类型返回信号列表 |
| 评分引擎 | `src/scanners/mw_signal.py`（已有） | 计算 B1 关注度 + MW 形态评分 |

### 2.3 与 v2.x 的关键区别

| | v2.x（旧） | v3.0（新） |
|------|------|------|
| 候选来源 | 五级硬过滤管道（5000+→3~5） | MW 信号直出，前端筛选 |
| B1 处理 | 无单独展示 | 关注度 ≥80 Tab 独立展示 |
| B2 处理 | 混在候选里 | B2 Tab，MW 评分降序 + 仓位建议 |
| 后端依赖 | pipeline.py / briefing.py / cockpit 数据库表 | 无额外依赖 |
| 历史回顾 | 不支持 | 日期选择器切换 |

## 3. 筛选与展示规则

### 3.1 B1 Tab「高关注B1」

| 项目 | 说明 |
|------|------|
| 数据源 | `GET /api/mw/signals?type=b1&start={date}&end={date}` |
| 筛选 | 关注度评分（`tech_score`）≥ 80 |
| 排序 | 关注度降序 |
| 卡片信息 | 股票名/代码、关注度徽章（极高/高）、H→L→C→B1 结构线、前高RS、回调深度、行业、B1涨幅 |
| 展开明细 | 关注度 5 因子明细（前高RS + 换手率 + 距H天数 + 回调深度 + B1温和度） |
| 用途 | 筛选值得等待 B2 的 B1，加入观察池。**不等 B2 不买入** |

**关注度门槛说明**：全周期验证，关注度 ≥80 的 B1 仅占 1%，胜率 59.0%，B2 确认率 55.5%。门槛设在此处确保每天驾驶舱只展示最值得关注的一批。

### 3.2 B2 Tab「B2确认」

| 项目 | 说明 |
|------|------|
| 数据源 | `GET /api/mw/signals?type=b2&start={date}&end={date}` |
| 筛选 | 全部 B2 确认信号（`b2_date IS NOT NULL AND b2_date > b1_date`） |
| 排序 | MW 形态评分（`score`）降序 |
| 卡片信息 | 股票名/代码、MW 评分徽章（分数/置信度）、H→L→C→B1→B2 结构线、前高RS、回调深度、行业、B2涨幅、**仓位建议条** |
| 展开明细 | MW 形态评分五子项（I2/D/I1/H/Sig）+ 延伸项 |
| 用途 | 决定买入和仓位。**B2 确认 = 可以买，MW 评分 = 买多少** |

### 3.3 仓位建议规则

基于 MW 形态评分和回调深度，在 B2 卡片上展示仓位条：

| MW 评分 | 回调深度 | 仓位 | 胜率 | 样式 |
|------|------|:---:|:---:|------|
| ≥ 70 | 任意 | **重仓** | 78% | 绿色底 |
| 50~69 | > 40% | **重仓** | 84% | 绿色底 |
| 50~69 | ≤ 40% | 标准仓 | 71% | 黄色底 |
| < 50 | > 40% | 标准仓 | 74% | 黄色底 |
| < 50 | ≤ 40% | 轻仓 | 62% | 灰色底 |

### 3.4 日期选择器

顶部提供日期输入框，默认最新交易日。切换到历史日期可回溯任意天的驾驶舱状态。数据直接从 `mw_signal_daily` 查询，无历史数据丢失风险。
