# MW 信号前端页面 · 产品需求书

> 版本：v1.1 | 日期：2026-06-03 | 状态：⏳ 待更新（B2 日期为主维度）  
> 页面路径：`web/mw-signals/index.html`  
> 后端 API：`GET /api/mw/signals` `POST /api/mw/scan`  
> 风格：hanako-glass（玻璃拟态 + 深浅双模）

---

## 1. 页面概述

MW 信号看板是用户与 MW 信号扫描引擎交互的唯一界面。核心功能：

1. **选择 B2 日期范围并触发扫描**：选好起止日期，点「查询」，后端扫描该范围内的交易日，检出 B2 落在该区间内的所有信号
2. **筛选信号**：按置信度、RS 强度、日均成交额三维度过滤
3. **查看信号详情**：点击卡片展开六阶段结构节点和评分明细
4. **人工复核**：点击股票代码跳转形态识别页面

**核心设计原则**：信号以 B2 日期为主维度。600584 的 B2=05-08，无论哪天扫描、哪天发现，它始终挂在 05-08 下面。日期选择器筛选的是 B2 发生日期，不是扫描日期。

## 3. 交互逻辑

### 3.1 日期范围 + 扫描触发

| 操作 | 行为 |
|------|------|
| 选择起始日期 | 仅记录，不触发任何请求 |
| 选择结束日期 | 仅记录，不触发任何请求 |
| 点击「🔍 查询」 | 触发 `POST /api/mw/scan` 扫描该日期范围内所有日期，扫描期间显示"⏳ 正在扫描..."。完成后自动调用 `GET /api/mw/signals` 加载结果 |
| 点击「📅 最新」 | 清空日期选择，调用 `GET /api/mw/signals`（不带参数），返回最新扫描日的数据 |
| 页面首次加载 | 自动调用「最新」模式 |

**设计决策**：为什么用显式按钮而非自动触发？
- 扫描全市场需要 ~15 分钟/日，自动触发会导致意外的长时间等待
- 用户可能需要先选好两个日期再统一提交
- 首次加载用"最新"模式，快速展示已有的最近数据

### 3.2 扫描状态

| 状态 | 显示 |
|------|------|
| 扫描中 | `⏳ 正在扫描 2026-05-27 ~ 2026-05-30，全市场5354只股票，请耐心等待...` |
| 扫描失败 | `扫描失败: {错误信息}` |
| 无信号 | `所选范围暂无MW信号` |
| 筛选无结果 | `无匹配信号` |

### 3.3 筛选器

三个下拉筛选器，叠加生效：

| 筛选器 | 选项 | 逻辑 |
|------|------|------|
| 置信度 | 全部 / ⭐⭐⭐高 / ⭐⭐中 / ⭐低 | `s.confidence === value` |
| RS250 | 全部 / RS250 ≥ 80（强势股） | `s.h_rs250 >= 80`。RS 为空的不通过 |
| 日均成交额 | 全部 / 日均 ≥ 5000万 | `s.c_amount_avg >= 50000000`（5000万元 = 50,000,000 元） |

筛选条件变化时即时刷新卡片列表，无需重新请求后端。

### 3.4 信号卡片

每张卡片显示一只股票的 MW 信号：

**收起状态（默认）**：
- 股票名称（可点击跳转形态识别）、代码、扫描日期
- RS250 值 | 横盘期日均成交额（万元）
- 置信度徽章（红=高 / 琥珀=中 / 灰=低）+ 分数
- 六阶段节点链（彩色圆点 + 日期 + 关键价格）

**展开状态（点击卡片）**：
- B2 详情：涨幅、收盘位置、突破均线条数、是否跳空
- B1 详情：涨幅、量比
- 调整段：跌幅
- 横盘段：振幅
- 评分明细：H/D/C/P 各 10 分，通过的显示绿色 ✅，未通过的显示灰色 —
- 底部链接：
  - `🔍 形态复核 →`：跳转 `http://localhost:8772/pattern-scan/?code={stock_code}`
  - `🎋 缠论分析 →`：跳转 `http://localhost:8772/chanlun-backtest/?code={stock_code}&mode=stock`

### 3.5 节点颜色编码

| 节点 | 圆点色 | 含义 |
|------|:--:|------|
| H 前高 | 🔴 红 `#ef4444` | 阻力位 |
| L 最低 | 🟢 绿 `#10b981` | 底部 |
| C 横盘 | 🟠 琥珀 `var(--accent)` | 蓄力 |
| B1 突破 | 🔵 蓝 `#3b82f6` | 首次试探 |
| P 整理 | ⚪ 灰 `var(--muted)` | 确认 |
| B2 突破 | 🟣 紫 `#a78bfa` | 趋势启动 |

### 3.6 置信度徽章

| 置信度 | 样式 | 分数 |
|------|------|:--:|
| ⭐⭐⭐ 高 | 红色底 + 红色边框 | 40 |
| ⭐⭐ 中 | 琥珀底 + 琥珀边框 | 30 |
| ⭐ 低 | 灰色底 + 灰色边框 | < 30 |

## 4. API 约定

### 4.1 查询信号列表

```
GET /api/mw/signals
GET /api/mw/signals?start=2026-05-27&end=2026-05-30
GET /api/mw/signals?date=2026-05-30

Response:
{
  "date": "2026-05-30",        // 最新扫描日期（范围查询时为空）
  "start": "2026-05-27",       // 仅范围查询时返回
  "end": "2026-05-30",
  "signals": [...],
  "count": 93,
  "dates": ["2026-05-30", "2026-05-29", ...]  // 所有可用扫描日期
}
```

### 4.2 触发扫描

```
POST /api/mw/scan
Content-Type: application/json
Body: {"start": "2026-05-27", "end": "2026-05-30"}

Response:
{
  "ok": true,
  "scanned": ["2026-05-27", "2026-05-28", "2026-05-29", "2026-05-30"],
  "count": 4
}
```

扫描是同步的——请求会阻塞直到所有日期扫描完毕。单日约 15 分钟，多日累加。前端需要容忍长响应时间。

### 4.3 API 代理

页面通过 `nav.js` 的 API 代理机制，所有 `/api/` 请求自动转发到 `http://localhost:8788`。

## 5. 技术实现要点

### 5.1 筛选逻辑（纯前端）

所有筛选器叠加，对已加载的 `allSignals` 数组进行客户端过滤，无需额外 API 请求：

```javascript
var filtered = allSignals.filter(function(s){
  if(conf && s.confidence !== conf) return false;
  if(rs && (!s.h_rs250 || s.h_rs250 < parseInt(rs))) return false;
  if(amt && (!s.c_amount_avg || s.c_amount_avg < parseInt(amt)*10000)) return false;
  return true;
});
```

### 5.2 日期参数格式

- 查询：`GET /api/mw/signals?start=2026-05-27&end=2026-05-30`
- 扫描：`POST /api/mw/scan` body `{"start":"2026-05-27","end":"2026-05-30"}`
- 注意：`start` 参数前不带 `&`，URL 格式为 `?start=...&end=...`

### 5.3 成交额显示

```javascript
// c_amount_avg 单位是元，显示转为万元
(s.c_amount_avg / 10000).toFixed(0) + '万'
```

### 5.4 RS 为空的处理

RS 数据可能为空（前高日期早于 RS 表覆盖范围）。此时：
- 卡片上显示 `RS—`
- RS 筛选器自动跳过该条（`!s.h_rs250` → 不通过）

## 6. 已知问题

| # | 问题 | 影响 | 处理 |
|---|------|------|------|
| 1 | RS 数据仅覆盖 2026-05-08 之后 | 前高在此之前的股票 RS 为空 | 前端显示 "—"，RS 筛选自动跳过 |
| 2 | 扫描期间页面阻塞 | 用户需等待扫描完成，无法做其他操作 | 显示进度提示。后续可改为异步+轮询 |
| 3 | 同一信号可能出现在多个扫描日 | 若 B2=06-02，在 06-02~06-07 的扫描中都会出现 | 这是设计行为——信号在 B2 后 6 天内可见，允许次日确认 |
| 4 | 全市场扫描耗时长 | 单日 ~15min，多日累加 | CLI 和 daily_update 可后台跑，前端扫描适合 1~3 天范围 |
| 5 | 无分页 | 信号多时（100+）页面较长 | 用筛选器缩窄范围。后续可加分页 |

## 7. 视觉规范

遵循 `hanako-glass` 风格：
- 字体：Instrument Serif（标题）+ Inter（正文）+ JetBrains Mono（数据）
- 卡片：`background: var(--card)` + `backdrop-filter: blur()` + 14px 圆角
- 深浅双模：CSS 变量驱动，右上角 🌓 切换
- 粒子背景：60 个琥珀色粒子 + 连线
- 导航栏：`nav.js` 自动渲染
- 响应式：卡片堆叠，移动端友好
